# UI-R37-STABLE：修正 R36 的振动与停止抖动

本页保留 R37 实现与发布验证。后续用户确认结束高频振动改善，但手转仍有不固定角度的快慢起伏。当前 **UI-R38-SMOOTH** 保留本页停止保持，并改进移动输入整形，见 [4015_moving_smoothness.md](4015_moving_smoothness.md)。下文“尚未烧录”指 R37 发布时的验证状态。

用户实测：R36 慢转顿挫更强，主轴停下后从轴容易高频振荡；滑行后的晚停稍有改善。本版先撤回会增强噪声反馈的控制变化，保留受约束追赶与输入前馈衰减。无需重新生成 CubeMX；适用于 4015 从轴、Curr Loop=On，两轴可交换主从。尚未烧录验证。

## 本轮修正

1. 撤回 R36 慢速时额外增加的速度 P。恢复 R35 的 0.05～0.10 A/(rad/s) 误差调度；移动时 I 仍为 0.5，原电流和保护阈值保留。
2. 撤回绕过参考轨迹、直接对原始主从角差做位置修正的通道。位置与速度前馈始终来自同一条受约束轨迹，继续按停止距离、速度和加减速限制追赶原始目标。Run Error 仍显示真实主从误差。
3. 删除 R36 末端 `-6*Error-0.5*速度` 的第二套 PD 捕获。保持原位置 P + 速度 PI + 电流 PI 结构，手停主轴时不再切到更强的速度阻尼反馈。
4. 主机输入安静的最短时间从约 5 ms 增至超过 30 ms，且仍需超过前次运动计数间隔的两倍。另以约 2.25 个编码器计数作为运动锚点变化阈值，容忍静止时 ±1 计数抖动。速度差分仍逐样本更新，不能把锚点间累计位移在多帧重复当作速度。
5. 输入安静超过 60 ms、从轴误差小于约 4 计数（0.088°）、参考速度小于 0.05 rad/s、估计速度小于 0.08 rad/s 时，允许进入近静止保持。
6. 保持期间冻结速度积分的继续累积，**保留已有负载补偿积分和电流闭环**；速度误差使用连续的 ±0.05 rad/s 小死区，避免几个计数的测速变化反复产生正反电流。它不清零目标，不关闭 PWM，也不屏蔽过流。
7. 确认主轴恢复运动、误差超过约 8 计数（0.176°）、或参考速度超过 0.15 rad/s 时退出保持，正常积分恢复。进出阈值不同，避免边界反复切换。每次 Follow 都重置运动锚点和保持状态，设置草稿不能修改正在运行的控制器。

4/8 计数是近静止状态的切换容差，不是任意负载下的定位精度保证。原始目标仍在持续更新；大角差会继续追赶。按 Run OK/KEY2 或发送 Stop 仍走既有停止/滑行流程，和这里的“手停主轴、Follow 仍启用”不同。

## 为什么撤回额外 PD 和 P 增强

R36 增强了速度波动到电流指令的反馈，短暂的输入安静又可能使末端控制参与。代码和噪声模型支持它们可能放大振动；用户报告证明了 R36 的板上结果变差，但尚未测得实机振荡频率及环路带宽，不能仅凭模型认定全部原因。

[Synapticon 的级联位置环说明](https://doc.synapticon.com/node/sw5.0/motion_control/control_loops/position_loop.html)建议采用位置/速度 P–PI 或 PI–P，通常不同时增加 D 和两级积分。[反馈滤波说明](https://doc.synapticon.com/actilink_s/sw5.6/motion_control/advanced_control_options/filtering/low_pass_filter.html)提醒噪声抑制和相位之间存在取舍。本轮保留原观察器带宽，并未用更重的从机反馈低通去掩盖振动。

试算中过强的电流指令限斜率增加了制动延迟，部分模型反而出现更大摆动，因此没有合入全局电流限斜率。也没有加入未经辨识的惯量、摩擦电流前馈或猜测频率的陷波器。

## 回归和对比结果

测试调用真实 M1 FOC、M2 控制器、协调器与协议；传感器、功率级和电流执行器为模型。电流执行器为 250 rad/s 一阶响应，电流到加速度增益为 300/1500/3000 rad/s²/A，均未实物辨识；模型不能替代真实 RL/PWM、电压饱和、惯量及温升测试。各工况都检查从轴持续启用、Iq 不超过 ±1.2 A。

新增 40/80 Hz、±1 个编码器计数的从机角度噪声；同时覆盖主从都有噪声、去掉静摩擦后的低摩擦模型、0.05 A 等效负载阶跃、保持 3 s 后再次移动主轴。噪声工况统计最后 1 s。

| 模型指标（M1 从轴） | R36 | R37 |
| --- | --- | --- |
| 有静摩擦、从机静止噪声，目标 Iq RMS | 约 3.69～3.85 mA | 约 0.37～0.48 mA |
| 同工况，目标 Iq 变化率 RMS | 约 1.26～2.02 A/s | 约 0.27～0.28 A/s |
| 无静摩擦、增益 3000、40 Hz 噪声，实际速度 RMS | 约 0.068 rad/s | 约 0.0057 rad/s |
| ±10°、4 Hz，幅值比 | 约 0.87～0.89 | 约 0.87～0.89 |
| 0.2 rad/s 匀速，实际速度起伏 RMS | 约 0.072～0.080 rad/s | 约 0.080～0.092 rad/s |

M2 对应噪声、负载及重新运动检查同样通过。负载阶跃后的目标 Iq 约 0.05 A，说明保持没有丢弃支撑负载的电流；保持后移动主轴能退出保持并重新跟随。最后一项明确保留了撤回增益增强的代价：本版优先减少电流振动，不能宣称所有慢转速度波动都更小。

既有位置阶跃、反向超调、±10°/4 Hz、滑行与大角差追赶的瞬态界限保留。R36 专用的部分慢速 RMS/最低速度界限恢复到 R35 附近的范围，并增加独立的保持噪声验收；这不是所有 R36 性能指标同时改善。

大角差拨转停止时仍可能落后约 3 rad，需要继续补角。模型追赶到 0.1 rad 范围约需 0.24～0.75 s；某些静摩擦模型仍有随后的小幅补角，不能承诺与主轴同时完全静止。补充的更高电流—加速度增益诊断暴露了原控制器的稳定范围限制；本轮没有辨识真实惯量，不能把 300～3000 范围的通过结果外推到所有空载/负载电机。

## 上板复测

烧录当前 Release 或 Debug，About → FW 应为 **UI-R37-STABLE**。保持从轴 4015、Curr Loop=On、Pos Speed=120、Speed Limit=120；先检查静止和慢转，再检查滑行停止与高速往复。无需修改 CubeMX、重新保存电机型号或调整过流阈值。

若仍明显振荡，优先记录实际从轴速度、实际 Iq、主从位置及 Run Error。JustFloat 的 M1/M2 位置为第 14/20 通道，速度为第 2/18 通道，M2 实际 Iq 为第 21 通道，跟随误差为第 25 通道。需要用实测数据核对速度环和电流环响应；10 kHz 是执行频率，不是已经测得的控制带宽。

## 构建与检查

电机/采样/编码器/HSO/协议、UI/存储/LCD、USB CDC 主机测试通过。Debug、Release 构建及最终 ELF/BIN 启动顺序、一致性检查通过；未烧录或进行本轮硬件闭环测试。

Debug：Flash **131012 / 131072 B**，余 **60 B**；RAM **21616 B**。Release：Flash **130236 B**，余 **836 B**；RAM **21520 B**。

为容纳保持逻辑，HSO 参数验证及使能入口采用大小优化；有限区间比较本身拒绝 NaN 和正负无穷，去除了重复分类代码，并对所有配置字段补充非有限输入拒绝测试。10 kHz HSO 主处理、ST 库和所有保护阈值保持原设置。
