# VREFINT 跟踪 ADC 参考电压（UI-R22-VREF）

## 估算值表示什么

VREFINT 是芯片内部约 1.2 V 的基准通道。将当前 ADC 读数与芯片出厂 `VREFINT_CAL` 比较，估算得到 ADC 实际使用的 VREF+ 相对 VSSA 的电压，而不是把 VREFINT 本身当成 ADC 满量程。

本板用户确认 VREF+、VDDA、INA240 REF2 接同一电源网，实测约 3.26 V，REF1 接 AGND。因此 Status 的 VREF 对应这路公共参考电源的滤波估算值；INA240 理想零电流输出约为它的一半（1.63 V）。该测量没有独立探测 INA240 引脚，不能反映走线压降、不同接地点的压差或瞬时开关尖峰。

STM32G431 的出厂校准值在 VREF+=3.0 V、12 位 ADC 条件下取得：

```text
VREF估算 = 3.0 × VREFINT_CAL / VREFINT平均ADC码
```

校准地址使用当前 ST 驱动的 `VREFINT_CAL_ADDR`，校准电压使用 `VREFINT_CAL_VREF`，不写死某一颗芯片的 ADC 校准码。该估计仍受 ADC、出厂校准和温漂误差影响，不等同于精密万用表。

## ADC 配置与时序

已同时修改 `FOC_two.ioc` 与 `Core/Src/adc.c`：

| ADC1 规则组顺序 | 通道 | 采样时间 |
| --- | --- | --- |
| Rank 1 | PB0 / IN15，母线分压 | 47.5 ADC 周期 |
| Rank 2 | 内部 VREFINT / IN18 | 640.5 ADC 周期 |

ADC 时钟 42.5 MHz，VREFINT 采样保持约 15.07 μs，超过数据手册要求的最小 4 μs。两路转换各计入 12.5 周期转换阶段，总耗时约 16.78 μs。

仍由完整注入帧之后、每五帧一次的软件 TIM6 UPDATE/TRGO 触发（约 2 kHz）。TIM6 不自由运行，保留上数前半段窗口检查，避免规则转换与下一次注入触发冲突。电流和相电压的注入组顺序、触发位置和采样时间均保持现有配置。当前窗口条件给下一注入触发留下至少约 75 μs；计算时长不代替示波器验证。

DMA 改为 4 个半字，循环内容为 `[VBUS0, VREFINT0, VBUS1, VREFINT1]`，半满和全满回调各消费一整对。回调频率与原来一致，每个规则触发仍更新一次母线读数。没有将阻塞读取插入 10 kHz 电流中断。

## 平均、滤波及换算

- 64 个连续有效 VREFINT 样本先在 ADC 码域求平均，约 32 ms 一组。
- 用平均值和出厂校准值反算 VREF+；第一组直接作为滤波初值，避免从猜测的 3.3 V 缓慢收敛。
- 后续每组执行 `filtered += 0.125 × (estimate - filtered)`，名义时间常数约 0.24 s，换算系数约每秒更新 31.25 次。
- 单个异常样本清除当前未完成平均组、增加 RefErr，并保留最后有效系数。0、4095 和对应估算范围不在 2.7～3.6 V 内的码值不进入平均；该范围针对本板标称 3.3 V 模拟电源。
- 通过一个对齐的 float 发布 `VREF / 4095`。控制 ISR 每帧只读取一次，由同一值派生电流和相电压比例；母线回调也使用同一个已发布系数。

```text
电流(A) = (当前ADC码 - 校准零点ADC码) × VREF / 4095 / (0.01 × 50)
相端电压(V) = 相电压ADC码 × VREF / 4095 × 11
母线电压(V) = 母线ADC码 × VREF / 4095 × 11
```

保留原始 ADC 码域的开机零点校准，运行中不重新学习带载零点，也不固定减去 1.65 V。两路电机的全部五个电流通道共用该换算。M1 软件过流和过载判断自然使用校正后的安培值，仍以原始电流样本计算，没有给电流保护信号增加平均滤波。

HSO 接收的电流、电压物理量随之校正。`st_hso.c` 的 6.6 A / 72.6 V 是 ST 定点库的固定归一化尺度，并非 ADC 当前参考电压或电流允许值，不跟着 VREF 动态改变。

## 启动与异常处理

在首组有效参考完成前，临时换算值按用户实测的 3.26 V 初始化，功率输出保持禁用，VREF 行显示 NO DATA。母线正常但参考尚未就绪时 Drive 显示 WAIT VREF；有效参考、母线稳定和电流零点校准均完成后才允许输出。

没有有效平均值持续超过启动后 200 ms，或最后一次有效系数更新超过 200 ms，会锁存 ADC REF 故障并关闭功率输出，采样继续。参考恢复后可以观察到 VREF 和 RefState 恢复，但电机不会自动重新启动；解决异常后复位再运行。无效的出厂校准值同样拒绝启动，不使用假定参考绕过检查。

## Status 核对

| 字段 | 含义 |
| --- | --- |
| VREF | 已测得的滤波 VREF+，显示至 0.001 V；首组完成前 NO DATA |
| RefState | WAIT：无有效平均；OK：近期有效；STALE：最后有效估计超时 |
| Ref R/C | 最新 VREFINT 原始码 / 本颗芯片出厂校准码 |
| RefCnt | 有效平均与滤波更新次数，正常约每秒增加 31 |
| RefErr | 被拒绝的异常 VREFINT 样本累计数 |

烧录后在 About 确认 UI-R22-VREF，等待 RefState=OK，再将 VREF 与万用表在 MCU VREF+/VSSA 处的读数比较。若持续不符，记录 VREF、Ref R/C、RefCnt、RefErr 和 ADC1Err，再检查参考通道与实际硬件；不能以显示三位小数认为精度达到 1 mV。
