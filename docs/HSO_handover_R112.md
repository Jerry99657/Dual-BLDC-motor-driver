# R112：HSO 接管后 FLUX 故障的处理

固件 `UI-R112-HFF`，Native 配置回执 112；协议结构、采样通道和存储格式保持不变。没有 CubeMX 配置变更。

## 实板报告与能够确认的范围

R111／4015／空载／12 V／Speed 45 rad/s，起转正常，进入 CONTROL 约 0.1 s 后停机：

- H Lost／H Gate：FLUX；H Time：92 us / 0；Drive：READY。
- H Flux：7645 µWb；H Actual：8.2 mWb；H Speed：25.9 rad/s。

没有报告计算超时；末帧观测磁链约为参考值的 1.073 倍，在既有磁链范围内。`FLUX` 同时用于观测磁链异常和阻抗补偿后的反电势幅值异常，单看 H Actual 不能判断是哪一项；R111 的 H Reject／H R EMF 还只保留此前 CAPTURE 的信息，无法直接解释 CONTROL 的故障。

代码检查发现 R111 的前馈启用没有向已有 PI 积分转移电压。CONTROL 前 50 ms 关闭前馈，随后 50 ms 将前馈直接叠加到已经建立电压的 PI 输出上，而且与既有 100 ms 电流交接重叠。本轮修正这一可验证的接管缺口；它与故障时序相符，但软件测试不能证明这就是实板 FLUX 故障的全部原因，仍需相同条件复测。

核对了本机官方 MCSDK 6.4.2 的 MotorControl.zip：HSO 配置模板将额定 V/Hz 磁链换算成物理 Wb 后传入 Flux_Wb。本工程的 active.flux_wb 原本已经是物理 Wb，未发现需要再乘／除 2π 的依据，本轮不修改磁链单位或参数。

## 修复

1. HSO 模型前馈在既有坐标系旋转和 I/F→Iq 电流交接的整个 100 ms 内关闭。交接完成后，由公共电流控制器执行 50 ms 启用渐变，不再在 HSO 返回的速度里隐藏另一层渐变。
2. 前馈启用增益变化时，同步转移 PI 积分电压：若未加权的模型电压为 F，增益由 g 变为 g+Δg，先执行 `积分电压 -= Δg × F`，再加入新的前馈。积分仍遵守原边界；正常速度／电流变化产生的前馈保留。没有把所有前馈变化都抵消，也没有清空运行中的 PI。
3. M1／M2 公共电流路径采用同样的无扰处理；停机／参数重载时继续复位增益。普通电压模式、六步、辨识和原有故障停机路径保持。

积分与前馈分担电压的衔接参考 [无扰切换](https://www.mathworks.com/help/simulink/slref/bumpless-control-transfer-between-manual-and-pid-control.html) 及 [带前馈的 anti-windup](https://www.mathworks.com/help/simulink/slref/anti-windup-control-using-a-pid-controller.html)。总请求限幅、实时 VBUS 缩放和积分回算继续保留 R111 的实现。

## 故障记录

CONTROL 出现最终拒绝时才记录诊断，不在正常控制周期反复计算诊断平方根。复用已有 HSO 记录字段：

- **H Reject**：反电势过低显示 `EMF LOW`，过高显示 `EMF HIGH`；其他原因保留其类型。
- **H R EMF%**：故障瞬间，补偿后反电势矢量幅值／按参考磁链与速度计算的幅值。
- **H R Deg／H R Hz**：故障瞬间的角度残差和频率差。
- H R Drift 为 CAPTURE 专用，CONTROL 故障时显示无效；H Reset 仍只计 CAPTURE 重置。

H Lost／H Gate 原 `FLUX` 保护代码保留；新增 detail 值 `EMF HIGH=21` 追加在原枚举末尾，LCD 与单 HTML 上位机均识别。记录在 Stop 后保留，下一次显式启动重置。

磁链范围、反电势幅值门限、20 个连续异常样本停机、100 µs 时限、ADC／电流／编码器／Break／KEY1 保护均未放宽。反电势幅值下限仍包含原来的低幅值底线，百分比必须结合 H Speed 阅读。

## 回归与局限

新增的控制器状态测试先在 R111 运行并失败：固定反馈、零电流误差、PI 已建立电压时，只渐变前馈启用增益，会在 50 ms 内额外改变约 2.191489 V。修复后，两轴双方向同一测试的最大变化约 0.000231 V（含 PWM 量化）；增益固定后，真实速度变化仍产生预期前馈。该测试没有电机反馈响应，不能把 2.19 V 描述成实板实测冲击。

上一轮 RL 模型从静止启动，HSO 边界桩又不会随电压改变其输出，漏掉了“PI 已建立电压后启用前馈”的场景；本轮补上该场景。独立 RL／dq 模型、总电压饱和、非有限输入恢复和实际 M1／M2 调用路径仍通过。

另加 HSO 诊断回归：保持观测磁链在参考值附近，独立改变补偿后反电势幅值。高／低两种异常仍按原连续 20 帧保护停机，记录正确的细分原因与幅值比，并在 Stop 后保持。专有 ST HSO 二进制在主机测试中仍使用桩，不能据此证明实板已经恢复启动。
