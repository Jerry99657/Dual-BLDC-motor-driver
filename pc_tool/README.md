# 双电机电脑端工具 · R86

本地 Python 服务＋浏览器界面，配套板端固件 **UI-R86-PC**。支持 USB CDC 和 USART1 两种连接；两种连接都在工具中选择相应 COM 口，均使用同一套 R86 二进制数据格式。

## 启动

在工程根目录执行：

```powershell
python -m pip install -r pc_tool/requirements.txt
python pc_tool/server.py
```

服务仅监听 `127.0.0.1`，默认打开 `http://127.0.0.1:8765`。也可以运行 `pc_tool/start.ps1`。如果端口被占用，使用 `python pc_tool/server.py --port 8766`。

模拟曲线，不连接开发板：

```powershell
python pc_tool/server.py --demo
```

退出服务使用终端 Ctrl+C。Python 环境需要标准库和 pySerial，不依赖 Tk／Qt 或外部网页资源。

## 连接和使用

1. 将板子连接到电脑。USB CDC 直接选择开发板的虚拟 COM 口；USART1 通过与板端电平匹配的串口适配器连接，使用 **115200、8N1**。
2. 点击刷新、选择 COM 口、点击连接。工具不会自动发送运行或对齐命令，也不自动重连、重放历史命令。
3. 默认采集组为 `Auto`，跟随板端工作模式；下拉框选择后点击“应用采集组”才发送 `Stream:` 命令。采集轴独立于 LCD View。
4. 曲线按单位分区，相同单位共用纵轴；可以取消不需要的曲线。无效值显示 `--` 并断线，不画成 0。
5. 通过轴、命令类型、目标输入发送指令，或者使用单行原始命令。**全局停止**直接发送 `Stop`。板端原有模式、来源、限幅和保护检查继续生效。
6. 右侧显示实时板端状态、输入来源、E1／E2、HSO／六步阶段、最近命令结果、控制峰值、数据年龄和序号／CRC 统计。未启用的轴不显示为正在使用的编码器故障。

**断开通信不等于停机。** 需要停止时先点击全局停止，或使用板上的 KEY1。当前没有新增通信丢失自动停机策略；关闭工具或拔线不改变原有板端控制规则。

发送成功只表示命令写入串口；是否接受，应结合板端最近命令结果与目标／状态变化判断。当前沿用“最近结果”，没有新增逐条命令 ID 的可靠应答机制，不适合多客户端流水控制。USB／UART 同时连接时，运动来源归属规则继续生效，另一来源不能覆盖活动目标；`Stop` 仍可全局停止。

## 采集组

| 命令 | 内容 |
| --- | --- |
| `Stream:Auto` | 编码器单轴 6 路，双轴 12 路，HSO 9 路，六步 6 路；HSO 比审查建议增加一路相对机械位置 |
| `Stream:M1`／`Stream:M2` | 固定轴常用数据 |
| `Stream:FOC1`／`Stream:FOC2` | q 轴命令、Iq／Id、两相电流、反馈速度、VBUS；q 命令按实际电流环状态显示 A／V |
| `Stream:ENC1`／`Stream:ENC2` | 整数编码器诊断：错误分类、原始角、年龄、全零帧前后值／计数／时间等 |
| `Stream:HSO` | HSO 资格计数、拒绝原因、磁链参数、捕获角差／频差／漂移、偏置等专题诊断 |
| `Stream:Six` | 六步候选周期、相位、周期比、过零计数、采样窗口、拒绝原因及启动反电势 |
| `Stream:Off` | 停止曲线，继续状态和心跳 |

专题诊断约 10 Hz；常用曲线最多 100 Hz，状态共用发送时隙、优先发送，稳定状态下通常约 90 Hz 曲线＋10 Hz 状态。主循环负载和传输忙可能进一步跳帧，应按板端时间戳判断时间间隔。

参数辨识仍从板上 `M1 Detect` 页面启动；电脑端这一版显示其阶段和完成结果，尚未增加电脑端启动辨识、修改全部 PID 或固件升级入口。

## HSO 机械位置

`hso.relative_position` 使用 HSO 电角度跨圈展开后除以极对数，不读编码器，也不以速度积分冒充角度观测。首次进入合格的 HSO CONTROL 时建立本次相对零点。

- 对齐、I/F 启动、学习、捕获阶段不标为有效测量位置。
- 停机、失锁、断采样或重新初始化后标为无效；下次启动重新建零。
- 不能恢复断电前的位置，也不能识别静止时外力移动；不提供机械绝对位置或零速保持能力。
- 本轮仅用于显示／记录，**没有开放 HSO 位置闭环或双机无感跟随**。

## CSV 记录与回放

点击开始记录后，文件保存在 `pc_tool/records/`，不提交到 Git。每行保留电脑时间、板端毫秒、包序号、重启分段、字段 ID、单位及值；无效值为空，状态另记为 JSON 行。记录发生在串口解析后，不依赖网页刷新，页面暂停绘图不停止采集记录。

导入本工具的 CSV，可以查看**最后一个采集组／重启分段的最近 20 秒**并拖动时间轴。文件流式读取，每条曲线最多保留 2200 点，避免长记录全部载入内存。CSV 回放时，右侧仍是实时板端状态，图表明确标为历史回放；普通运动发送被拦截，全局停止仍可使用。“返回实时”恢复实时绘图。

## 协议与验证边界

R86 替换原来的 25 路 JustFloat。旧 VOFA JustFloat 配置不能直接解析新帧；原有文本命令继续使用，单条不超过 63 个 ASCII 字节，工具自动附加换行。

完整字段契约、带宽、Flash 占用和测试见 [R86 实施说明](../docs/PC_tool_R86.md)。已完成 C／Python 交叉解析和前端脚本／DOM 模型测试；本轮 Windows 界面自动化因无法可靠识别浏览器 URL 而停止，**尚未完成真实浏览器视觉和实板 USB／USART 联调**。不宣称主机模型验证了 ST 二进制的真实观测精度或控制耗时。

接口参考：[pySerial 官方 API](https://pyserial.readthedocs.io/en/latest/pyserial_api.html)。
