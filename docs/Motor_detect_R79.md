# R79：电感、磁链与反电动势常数辨识

固件 **UI-R79-ID**，2026-10-25。在已经由用户实板确认正确的 R78 极对数／电阻检测之后，增加等效对齐电感与永磁磁链辨识。集成在同一固件，保留有感、双机、HSO、六步和现有保护。此次没有改 CubeMX 初始化、HAL、ST 库或 KK_UI 核心。

## 操作

1. 使用 **Single M1 + 编码器反馈**，关闭 HSO Feedback、Six Step。ENC1 正常，原有上电对齐完成，电机处于停止状态。无需重新生成 CubeMX 代码。
2. 电机空载、转轴可以自由转动。首次建议用稳定的 12 V 母线和默认 `I test 300 mA`；上／下键仍可在停止时设置 100～500 mA，步长 50 mA。
3. 进入 `Settings → Motor → M1 Detect`，按 OK。流程为：

   `RS LOW → RS HIGH → POLES + → POLES - → LS HOLD → LS PULSE → FLUX RAMP → FLUX TEST → DONE`

   2804／4015 的整次检测约 43～45 秒，期间包括正反转和用于磁链测量的旋转。磁链阶段最终为 **80 electrical rad/s**，11 极对约 69.4 rpm、7 极对约 109.1 rpm；这里的 80 是电角速度，并非机械角速度。
4. DONE 后自动关闭输出。左／右键翻看四组结果：`PP/R`、`Ls … uH`、`Flux … uWb`、`Ke … V/krpm`。上／下键调整测试电流并清除本次草稿，便于重新检测。
5. DONE 后按 OK 排队保存，等到 `Saved`。重新进入会显示已保存结果，左右键仍可查看，按 OK 才开始新检测。旧版存档只有 PP/R 时，另外三页显示 `NO DATA`。

检测中 OK 停止；KEY2 停止并返回；KEY1 仍是独立的全局停机。运行中的电流目标不能修改。任何阶段取消、采样／编码器／电流等故障或结果校验失败，都会关闭输出，本次完整结果保持无效；此前已经保存的结果不会被失败草稿覆盖，不自动重试或重新启动。

## 结果定义与保存

| 显示 | 定义 |
|---|---|
| PP | 极对数，正负号为 ENC1 相对测试电角度的计数方向 |
| R | FOC 等效星形相电阻，单位 Ω；不是三角形内部单支路阻值 |
| Ls | 电流对齐方向的小信号等效电感，单位 µH；未分别测 Ld、Lq，不能将它解释为已测得两轴平均值 |
| Flux | 相永磁磁链峰值 λ，单位 µWb |
| Ke | **线间反电动势 RMS／机械 krpm**，单位 V/krpm；不是相峰值 V/(rad/s) |

换算关系：`Ke = sqrt(3/2) × λ × pole_pairs × 2π × 1000/60`。例如 λ=7500 µWb、11 极对时，Ke≈10.58 V/krpm。与厂商参数比较前必须核对其相／线、峰值／有效值和机械／电气速度约定。

结果保存到 W25Q64 原来的 A/B 配置扇区（0x0000／0x1000），配置版本升级到 **v5**，新增 `motor_detect_l_uh`、`motor_detect_flux_uwb`。Ke 由磁链和极对数计算，避免保存重复且可能不一致的数据。继续使用快照、序号、CRC、写后校验和异步保存；v1～v4 会迁移，v4 的原有 PP/R 保留，新增字段默认为 0。

当前仍只保存最后一次完整检测结果。**不会自动写入 2804／4015 预设、PID、保护阈值或 HSO 配置**。尤其不能用本次小电流测试推定额定／最大电流。

### 电感

当前电流采样为 10 kHz，ADC 与 CCR 预装载存在延迟；因此不直接采用单周期 `L=U·dt/di`。测完极对数后，先保持 0.5 倍测试电流 500 ms，再施加围绕原低档电压的正负扰动，每个平台 2 ms，共 256 个平台。电流保持相同极性，扰动幅值略作变化，以减小死区和确定性 ADC 量化的影响。

将上升／下降波形带符号平均，丢弃切换后的前四个采样点，再分别累加三个连续的四采样窗口。恒压 RL 响应的相邻窗口差分之比满足：

`a = (late - middle)/(middle - early) = exp(-Rs × 4Ts/L)`

由此求 L，不需要假设已经到达稳态，也不依赖第一帧恰好发生在电压切换点。检查信号幅度、衰减比、结果范围与转子静止；失败提示 `LS SIGNAL`、`LS RANGE` 或 `LS MOVING`。用于该有限比值范围的对数采用范围缩减与 atanh 级数，避免引入完整 libm log/error 代码；截断误差远低于 ADC 测量误差。

此方法主要面向当前毫亨级云台电机。单周期衰减太快、信号接近量化／噪声时应拒绝结果，不保证适用于低电阻、微亨级穿越机电机。温度、转子位置、磁饱和也会改变电感。

### 磁链

采用独立的 d/q 电流积分调节器和强制旋转电流矢量，按 20 electrical rad/s² 加速到 80 electrical rad/s；5 秒后分别统计两个完整机械圈。使用本次测得的极对数和原始编码器累计位移求实际电角速度，必须在 72～88 electrical rad/s 内，两圈磁链结果相差不超过 10%。失步、锁转或磁链异常不发布完整结果。

稳定旋转坐标系的电压方程为：

`Ed = mean(Ud) - Rs·mean(Id) + ωe·Ls·mean(Iq)`

`Eq = mean(Uq) - Rs·mean(Iq) - ωe·Ls·mean(Id)`

`λ ≈ sqrt(Ed² + Eq²)/ωe`

先平均矢量再求模，避免对每个带噪声样本求模导致正偏差；也不需要事先知道磁链或编码器电气零偏。这里是**编码器辅助参数辨识**，不是无编码器辨识或 HSO 接管。

电压采用现有调制器基于占空比与实时 VBUS 得到的周期平均指令电压。原来的相电压 ADC 在 PWM 固定位置采样，前端约 40 µs RC，单点值不能直接当作周期平均值，所以本次没有直接塞入公式。结果仍包含逆变器死区、压降、Rs 偏差和离散时序的影响，属于初步辨识值；仿真误差不能当作实板精度承诺。磁链需重复实测，并与不同测试电流／母线电压下的结果比较，再决定是否用于 HSO。

## Flash 与验证

只重构用户层重复的限幅、两轴电流 PI／抗饱和、数值解析和界面初始化；LTO 输出重新组织函数／数据布局以共享常量池。没有修改 HAL/ST/KK_UI 核心源码或其编译选项，也没有删功能或扩大链接器的 Flash 区域。Debug 保留调试信息，HSO 运算仍为 O2。

最终 Debug／Release：Flash **131064 / 131072 B，余 8 B**；RAM **23112 / 32768 B**。容量仍非常紧张。原有 RWX LOAD 段链接警告继续存在。

独立平均 PWM／RL／永磁转子模型覆盖两种 R/L/p、电压 12／20 V、正反编码器、跨零拒帧、ADC 量化及噪声、额外 1／2 周期 PWM 延迟。典型 2804 模型得到 L=884 µH（真实 860 µH）、λ=7462 µWb（真实 7500 µWb）；4015 模型得到 L=1326 µH（真实 1300 µH）、λ=7437 µWb（真实 7500 µWb）。加入延迟／噪声的电感最大偏差约 4%，磁链约 1.3%。另测 12 mWb 磁链，防止结果依赖某个固定磁链常数。
