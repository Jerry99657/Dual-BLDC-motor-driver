# R114：编码器 FOC 时序与逆变器误差补偿

固件 `UI-R114-INV`，Native 配置回执版本 114。两路编码器 FOC 共用补偿实现；已实板验证平稳的 R113 HSO 保留纯 PI、完整电压请求矢量限幅及积分回算，不增加模型电压、角度超前或死区补偿。六步、对齐和参数辨识继续使用原电压调制接口。

## 时序

- MT6701 两路成功采样同时发布角度和 CS 拉低时的 DWT 时间戳，使用双缓冲发布，避免 ADC 高优先级中断读到半个样本。坏帧不刷新角度、时间戳或健康状态；健康准入、三周期陈旧保护、SPI 超时和低频恢复策略不变。
- 电流帧增加两路采样时刻：ADC 同步时钟 HCLK/4、注入顺序不变时，M1 的 U/V 采样保持结束约为中心触发后 50 个 CPU 周期（0.294 µs），M2 约为 630 周期（3.706 µs）。根据实际 CNT、方向和 PSC 反推本帧中心，成功成对采样才发布时刻。
- Park 使用预测到相应电流采样时刻的编码器电角度；逆 Park 使用预测到下一次 PWM 更新锁存后半个 PWM 周期的角度。两路各用本轴极对数和带方向的实测机械速度，不用目标速度，也不重复反转编码器方向。
- 时间差按有符号 DWT 差值处理，支持计数回绕；超过 ±1 ms 或速度非有限时不外推。原健康门限仍负责禁止陈旧编码器参与运行。
- 当前 TIM1/TIM8 为 170 MHz、PSC=0、ARR=8499、中心对齐模式 3、RCR=0，更新边界间隔约 50 µs；控制周期约 100 µs。计算时越过半周期也会重新选择下个边界。距边界不足 128 个 CPU 周期时最多重算三次，无法满足则本次写中性矢量；原整个 ADC 控制中断的 100 µs 保护继续有效。

这些时刻是基于计数器和采样顺序的估计：包含 SSI 传输等待，但没有声称测得 MT6701 内部滤波延迟、ADC 触发同步延迟或线路传播延迟。中心触发与 CNT=0/ARR 相差约一个定时器刻度，也仍属于本轮近似。电流滤波器的动态不作为纯延时重复补偿。

## 三相 PWM 提交

写 CCR1/2/3 的短临界段临时设置 UDIS，防止一次硬件更新只锁存新旧三相比较值的一部分，随后恢复原 UDIS 和 PRIMASK。此提交方式供所有原调制调用共用；不产生 UG，不重置计数器，不操作 MOE/CCER，不改变死区或初始化配置。硬件 Break 仍可异步关闭功率输出。

HSO 的电压计算、PI 回算、采样和启动参数仍按 R113 执行；其共同变化仅为三相预装载提交的完整性，边界附近可能整体延后一轮锁存，不能称所有边界情况下时序逐周期完全相同。

## 逆变器标称模型

依据用户提供的实际器件手册：

- JSM6288Q，手册第 5 页：内部死区最小 100 ns、典型 200 ns、最大 300 ns；第 7 页给出输出边沿定义。该数值不是 FD6288Q 的数据。
- CSD18540Q5B，手册第 3 页：25 °C、VGS=10 V 的导通电阻典型值 1.8 mΩ；4.5 V 栅压、温升或其他工作点不能直接视为相同电阻。手册大电流条件的开关时间和二极管压降没有直接用作本板补偿常数。

- [JSM6288Q 手册](D:/Data/Downloads/C19077370_栅极驱动芯片_JSM6288Q_规格书_WJ1795642.PDF)

编码器调制读取各自定时器的实时 `BDTR.DTG` 和 `CR1.CKD`，支持 DTG 全部四段编码及 CKD 的 DIV1/2/4。当前 DTG=17、CKD=DIV1 对应 MCU 死区 100 ns。模型初值取 MCU 死区与驱动器典型 200 ns 的较大值，**没有把两者直接相加，也没有声称它就是实测等效死区**。驱动器传播延迟、MOSFET 开关时间、栅压与负载变化仍需波形标定。

每相估计为：

```text
d_dead = min(0.005, max(t_MCU, 200 ns) / T_PWM)
u_loss = VBUS * d_dead * clamp(i / 0.1 A, -1, 1) + 0.0018 Ω * i
```

按电流极性给三相参考电压增加上述估计。±0.1 A 区间平滑过零，避免硬符号翻转放大电流零点噪声；死区项限制在母线的 0.5%。M1 使用三相采样，M2 的 W 电流由 U/V 重构。该模型随实时母线变化，不新增 UI 或 Flash 存储设置。

调制后读取实际写入的整数 CCR，去公共分量并减去同一标称损耗，估计最终 dq 电压供积分回算。它是模型回算值，不是 ADC 实测端电压。小于一 PWM 刻度的回算差不累计到编码器模式的积分，否则旋转中的刻度量化会导致零电流误差下的 PI 漂移；矢量限幅造成的超出刻度差值仍回算。HSO 保留原 R113 回算算法。

原实时 VBUS／型号电压上限、5% 电压余量、dq 电流目标限制、非有限输入保护、过流、过载、ADC、编码器、HSO、KEY1、硬件 Break 和显式手动重新启动均保留。

## CubeMX 与验证

本轮无需修改 CubeMX；未改 `.ioc`、生成初始化、HAL/LL/CMSIS、USB 中间件或 HSO 官方库。用户驱动读取生成句柄对应的实际寄存器，不写死外设地址或 DMA 通道。`scripts/check_cubemx.py` 新增死区编码／CKD 和三相 PWM 预装载检查；当前不支持的新频率、注入顺序或计数模式仍明确拒绝构建，禁止静默覆盖生成值。

验证结果：

- 48 项配置变更接受／拒绝回归，包括 DTG/CKD、PWM 配置缺失、DMA 重分配和 KEY1 换组；每次正常构建执行配置检查。
- 新逆变器回归：独立定时器更新事件模型，在每次 CCR 写入间插入硬件更新，确认无三相混合锁存；原 UDIS/PRIMASK 保持。两轴、正反转、上下计数、DWT 回绕、边界退避、全 DTG 编码和时钟比例通过。
- 12/20 V 标称桥臂损耗逆模型、平滑过零、补偿上限、CCR 电压估计、NaN 中性输出和 HSO／旧路径绕过通过；12000 点旋转的零误差 PI 不发生量化积累漂移。
- 完整 motor_host：电流环、独立 RL/dq 模型、双机／主从、HSO、六步、辨识、采样、编码器、协议、双数据格式通过。真实 LL 中断与采样联合回归、UI／设置、单 HTML 控制台与 Edge 通信握手通过。
- 两份 ARM 镜像启动和 ELF/BIN 一致性检查通过；211 个受保护文件和官方／核心编译命令相对本轮 R113 基线不变。已有 RWX 链接提示沿用。
