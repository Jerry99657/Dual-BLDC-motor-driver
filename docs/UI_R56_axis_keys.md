# UI-R56-KEYS：长按左右键选择电机

双独立模式的 Run 页改为长按左键选 M1、长按右键选 M2。稳定按下后约 600 ms 执行，一直按住只执行一次；选择当前轴也不会停止电机或切换控制模式。两路各自的运行状态、草稿和确认目标继续保留。

短按左／右在松手稳定 20 ms 后切换控制模式，仍按原规则先停止当前轴、再手动确认启动。按下时不会先执行短按，因此长按切轴不会误停电机。计时使用无符号差值，兼容系统毫秒计数回绕。进入 Run 的动画期间已经按住的左右键，需要释放后重新按下。

上下键调值和长按连发、OK 确认／启动／停止、KEY2 停止两路并返回保持原行为。左右同时按下、斜向组合、OK／KEY2、离开页面、外部切轴／切模式或运行故障会取消尚未完成的切轴手势。单机、同步、手动主从、首页、菜单及 Run Steps 不采用此长短按分类，保留原来的按键规则。

Run 底部显示 `LR hold` 提示。菜单里的 Axis M1 / Axis M2 仍可使用，当前轴继续延迟保存；退出 Run 后等待 `Save: Saved` 再断电。

KEY1 已解除切轴绑定，保留 PD13 上拉输入。本次只完成切轴迁移，未接入 KEY1 的全局暂停／恢复逻辑；恢复策略和主从暂停期间位移的处理仍需单独定义。

## 验证

主机回归覆盖三种控制模式中长按切轴不停止输出、两台同时运行时的选择、持续按住不重复切换、短按仅松手执行一次、释放抖动、方向组合、OK／KEY2 优先、故障／上下文取消、转场按键隔离、长按后断电保存、前台停顿及毫秒计数回绕。既有 UI、首页字号／居中、HSO ON、存储和 LCD 驱动回归通过。KK_UI 核心与控制算法未修改。
