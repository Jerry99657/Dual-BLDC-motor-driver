# R129：六个普通按键统一到 TIM2 输入层

固件 `UI-R129-KEY`，Native 回执编号 129。基线为 R128。

## 唯一物理输入流程

`TIM2 1kHz → GPIO 快照 → 消抖／识别 → 静态事件队列 → 主循环领取 → KK_UI 页面分发`

六键在所有页面、单机、独立、同步和 Follow 中使用同一流程。KEY1 继续使用已有的优先级 0 EXTI 全局停止，不参与六键采样。无需修改 CubeMX；GPIO、引脚、定时频率和优先级保持生成配置，ST HAL／LL／CMSIS／USB／HSO 源码不变。

- 只有 `ui_input_tick()` 读取六个物理 GPIO，仍在现有 TIM2 更新分发中、外环前调用。共端口时一次 IDR 快照，分端口自动回退到生成引脚表。
- 六键独立消抖 20 ms。方向键首次重复等待 300 ms，按住达到 800／1500 ms 后间隔分别为 100／60 ms，此前为 160 ms；OK／Back 仅触发按下事件。
- 左右键额外提供 600 ms 长按及消抖后的松开事件，供双独立 Run 区分长按选轴与短按换模式。组合键取消也在采样层识别，覆盖整个组合动作落在两次前台服务之间的情况。
- TIM2 不调用 KK_UI API、绘图、存储、通信或电机业务。页面与电机动作继续在主循环执行，捕获可靠性与动作执行延迟分开。

## 事件交接与保护

16 项静态 FIFO 保存普通短按顺序，同一键连续待处理的重复事件合并。同键两个完整短按仍可保留为两个按下事件。Back 优先取消待处理操作，避免等待在旧启动命令之后；队列满会清除积压并屏蔽当时按住的键，直至释放。超过 1 s 的未处理积压被丢弃。

页面、Run 轴／工作／控制模式及全局停止上下文变化取消旧事件；正常停止、故障停止、页面退出也取消旧输入。长按跨轴、故障恢复不会把旧事件解释为重新启动。取消不会自动启动或恢复电机。

`ui_input_poll()` 只领取队首，不读取 GPIO。`KK_UI_Update()` 通过显示传输检查后调用 `KK_UI_InputAccepted()` 确认出队，再处理导航及业务：

- 检查先失败：当前事件尚未执行，方向事件保留；确认／返回取消并等待物理释放。
- 分发后提交显示失败：当前事件已经出队，不会在恢复后重复加减或重复启动／停止。
- 确认前发生取消、队列满或过期：旧确认不能删除新到达的事件。

转场期间按键不穿透；持续按住方向键可在转场结束后重新等待重复延时。初始按住的键需要释放后再操作。上位机离开本地编辑器的辅助 Back 改为有间隔的规范化事件，无需模拟 GPIO 脉冲。

## 删除的重复路径

- 主循环物理 GPIO 扫描。
- 仅为双机 Run 的 OK／KEY2 保存短按的局部捕获、消费与松开注入状态。
- KK_UI 中六份物理键候选电平、消抖和重复计时状态。
- Run 左右键的前台原始电平轮询、松开计时和长按计时。

应用仍保留“哪一个左右手势属于当前 Run 上下文”的一个键值；它用于业务取消，不再识别物理电平或计时。统一流程仍需要事件队列和上下文取消，未通过删除这类保护压缩体积。

## KK_UI 项目副本适配

输入接口使用 `KK_UI_Input` 原填充字节增加 `key_event`，结构保持 4 B；新增长按／松开来源、转场状态查询和输入接受通知。KK_UI 只路由已识别事件并处理页面／覆盖层／转场屏蔽。绘制、字体、布局、动画、刷新所有权均保留。

这是工程既有 KK_UI 副本的输入端口调整，未修改配套 Skill 资产或 ST 官方库。移植参考同步记录此工程的接口契约。保护核对仅允许四个 KK_UI 输入相关文件及 `main.c` USER CODE 中一处调用替换，检查其余 UI 代码和官方编译选项与基线一致。

## 验证

- 真实 UI：35 ms 按压完全落在 80 ms 前台访问间隔内，双机 OK／Back、首页左右、Run 上下仍各执行一次；按键动作仍在前台执行。
- 独立输入夹具：六键、同键双击、不同键顺序、抖动、组合键取消、重复合并、长按／松开、领取／确认、迟到确认、满队列、过期、上下文取消、软件导航、毫秒回绕。直接改变 GPIO 而不运行 TIM2，不会改变前台输入。
- 显示错误：检查前失败可恢复方向输入；提交失败发生在分发之后时不会重复加减；按住确认／返回不会穿透恢复。
- 既有 UI／设置／对齐／Follow／长按／连发、存储、LCD 驱动、协议／JustFloat、HTML 和 Edge 串口格式／恢复回归通过。
- 重映射 GPIO：共享／分散端口、不同引脚及三种有效电平掩码，全部 64 种六键组合通过。主循环没有 GPIO 读取。
- 实际 Cortex-M4 链接代码：19 组 TIM2 路径，包含消抖、优先级、重复、长按、松开、满队列、过期与回绕。计数记录在 `build/keys-r129/input-work.json`，包含外设／查询边界替代，不能作为板上周期或微秒数。
- 真实 IRQ／采样集成、KEY1／Break、启动向量及外环超期处理回归通过。所有控制和保护门限保持原值。

识别对象由两个键扩大为六个键，TIM2 的输入识别工作增加；本次没有将其描述为控制中断提速。上板应复测双机运行的 `Outer Max`、`Outer Jitter`、`Outer E/G/S`，以及短按／长按操作。
