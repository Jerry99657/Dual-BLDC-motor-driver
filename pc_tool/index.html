Run 控制

Speed：rad/s；Angle：rad；Throttle：%；Torque：电流环 ON 为 A，OFF 为 V。

命令由板端准入和限幅。连接、切换采集组不会启动电机；断开通信不等于停机。

CSV 回放

直接保存 CSV 到电脑。导入本工具生成的 CSV，拖动时间轴检查历史曲线。

HSO relative_position 是本次连续锁定后的估算相对位移，每次启动重新建零；不是断电保持的绝对位置。

每条命令显示编号与板端回执。超时表示结果未知，运动指令不会自动重发。

电机参数辨识

使用板端现有 Single M1 编码器辨识，电机会转动。保存结果不自动替换型号预设；进度与结果见实时板端状态。

板端诊断详情

复用板端 Status 行；逐行采样，带板端时间，不改变 LCD 当前 View。R95 的 Diagnostics 附加完整中断时序、首次故障和 CPU 异常记录；仅停机后可清除，清除不会解锁保护。
