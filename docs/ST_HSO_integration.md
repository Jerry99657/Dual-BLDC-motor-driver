# ST HSO 接入与试运行（UI-R25-STOP）

R25 增加 Run 停机快照和编码器错误分类，见 [Run_stop_diagnostics.md](Run_stop_diagnostics.md)。R24 支持 Settings 选择 2804/4015，切换后重载模型与极对数并清除旧磁链学习/资格，不自动接管。两套初始磁链均为 0，需要对各自电机重新辨识；4015 电感的测量口径仍需核实。见 [Motor_profiles.md](Motor_profiles.md)。

R22 使用 VREFINT 平均及低通滤波估算 VREF+，校正 HSO 输入电流、电压的物理量；ST 库的固定归一化尺度保持不变。规则组采样窗口、参考诊断与验证范围见 [VREFINT_reference_tracking.md](VREFINT_reference_tracking.md)。R21 的可选 ENC2 停止探测、R20 的 USB 发送修复也继续保留，HSO 控制策略仍为下述 R19 规则。

R19 按用户要求改为实测 45rpm 机械速度边界：高于边界的正常减速保持 HSO，目标低于边界时先
用 HSO 减到边界再返回编码器。撤销大幅改速提前返回；HSO 减速参考斜率为 50rad/s²。
Speed 仍为 rad/s。完整规则及验证范围见 [HSO_recovery.md](HSO_recovery.md)。

R18 的待处理失锁先处理、再执行新命令的修复继续保留；其中大幅改速提前返回的策略已由 R19 替代。

R17 将正常低速/停车/反转返回编码器与真正失锁分开；真正失锁先停机，反馈健康时可用新 Speed
直接重新起转，并保留原因。Feedback 状态、速度余量和完整操作见 [HSO_recovery.md](HSO_recovery.md)。

R16 针对实板 `H Gate=OK/ANGLE`、`H Qual=0～24/200 ms 0/20`，调整首次资格的
短暂角度越界处理。R15 只增加了通过资格后的保持滞回，首次资格仍被单帧越界清零。
新规则累计严格合格的 2000 帧；15～20°（20°不含）的小角度越界不计入进度，
仅允许每次累计最多 50 帧（5 ms）、连续最多 10 帧（1 ms）。超过任一限额立即清零。
因此不是按错误角度取得资格，首次累计过程至少约 97.5% 的帧仍需满足 <15°。
`Use` 当前帧仍必须 <15°，同时通过所有严格入场检查。R15 的保持与严重故障规则不变。

R15 根据实板反馈（100 rad/s，H Error 约 -5～15°、H Time 68 us）分离接管资格与保持判定，
增加角度/速度共同的 10 ms 接管过渡，并显示阻塞/失锁原因。68 us 低于软件周期门限，
但不能排除未记录的采样误差；本轮不是电机兼容性或无感稳定性的实板验证。

R14 仅将手动加载时的过载参考改为 0.8 A、预算改为 3 秒，保留 2 A 停机和原有电流目标限幅；详见 [2804_current_limits.md](2804_current_limits.md)。

R13 同步 VBUS 规则采样与注入组，避免规则转换被注入抢占导致首项误为 0 的勘误风险；R12 增加的电流快照继续保留。详见 [current_adc_diagnostics.md](current_adc_diagnostics.md)。

本版另按当前电机铭牌将额定/峰值电流修正为 0.5 A / 2 A，降低对齐电压并加入
覆盖所有运行模式的过流/过载保护，详见 [2804_current_limits.md](2804_current_limits.md)。

本工程直接链接 MCSDK 6.4.2 的官方 `libHSO.a` 和 `libImpedCorr.a`，无需再建立
Workbench 工程。HSO 核心是二进制；可以修改的部分是 `mycode/st_hso.c/.h`、采样、
启动/切换逻辑、控制接口、协议和 UI。供应商文件、来源与许可证在
`ThirdParty/ST_HSO/`。没有将其他观测器冒充 ST HSO。

## 当前可用功能

- 电机 1：10 kHz 同一 ADC1 JEOS 中运行阻抗补偿、HSO 和原有 FOC。
- 默认仍由 MT6701 控制。HSO 在旁路计算角度、电角频率、机械速度和磁链，供对比。
- 可以用原有编码器控制转动，辅助估算磁链，再运行官方 HSO。
- `HSO:Use` 支持旋转中的实验接管；10 ms 小角度过渡后，FOC 电角度和速度反馈取自 HSO。
  编码器仍需连接，继续做独立有效性校验。
- 位置模式继续使用 MT6701；切到位置模式会退出 HSO 接管并清零原目标。
- 本次没有加入脱离编码器的静止启动、PolPulse、ZeST 或完整 ST Motor Profiler。
  不应把本版当作已经验证的全速域无感驱动。
- 电机 2 的原有采样/编码器诊断保持现状，未开放功率输出。

## 最短试运行步骤

1. 烧录 `build/Debug/FOC_two.bin` 或 ELF。About → FW 应为 **UI-R19-45RPM**。
   等待原有零点标定结束；Status → Drive 为 READY。
2. 当前 `MOTOR_2804.psi_f = 0`，所以 HSO 显示 **WAIT FLUX**。这表示尚未给定
   磁链，不是算法没有接入。可填写已测参数，或按下面的方法估算。
3. 用现有 Run 速度模式让电机平稳转动，例如机械速度 20 rad/s；也可发送：

   ```text
   Speed:20
   ```

4. 稳定后，通过 USART1 或 USB CDC 发送带换行的命令：

   ```text
   HSO:Learn
   ```

   HSO 显示 LEARNING。有效电频率至少 5 Hz（7 极对约 4.49 rad/s）；建议先在
   20～30 rad/s、空载、稳定转速下对比。学习需要连续约 1 秒有效稳定数据；
   加减速、编码器异常、ADC 饱和或估算离散过大会重新累计。
   成功后 H Flux 显示非零的 **uWb**，HSO 转为 OBSERVING，满足校验后为 TRACKING。
   这里估算的是物理永磁磁链，不是 ST Workbench 的 `ratedFlux` 字段。
5. 对比 Status → H Speed / H Error，确认转向、速度和角度一致，H Time 小于
   100 us 且右侧超时计数不增加。H Error 是 HSO 相对已标定编码器的电角误差。
   在多种稳定速度、两个方向都确认后，保持转动再发送：

   ```text
   HSO:Use
   ```

   HSO 显示 **CONTROL** 表示已接管。没有满足条件时拒绝，维持编码器控制。
   不会通过该命令自动启动或自动提高速度。
6. 结束试验可发送 `Stop` 或 `HSO:Encoder`，退出接管并清零输出目标。
   `Speed:0`、低速和反转目标先由 HSO 减至实测 45rpm 再正常返回编码器，不因目标改动直接退出。
   真正观测异常先零输出停机，反馈健康时新 `Speed` 可直接用编码器起转；不会因观测恢复自行重启。
   Run 页同样可重新确认目标启动；采样或编码器异常仍阻止运行。详见恢复文档。

该磁链估算是项目新增的**编码器辅助稳态估算**，不是 ST 官方自动辨识器。
它依赖 Rs、Ls、相序、电流极性、端电压比例/RC 和编码器零点正确。应在多个
稳定转速/方向下复测结果的一致性，再尝试接管。若估算长期不完成，先检查这些
量和电频率；不要直接放宽接管误差门限。

## 参数命令

命令区分大小写，以 LF 或 CRLF 结束，一行最多 63 个有效字符。USART1 和 USB
各有独立拼包缓冲；超长行整行丢弃。HSO 数字不接受 NaN、Inf、缺项或多余字符。

| 命令 | 含义 |
| --- | --- |
| `HSO:On` | 开启/重新初始化旁路观测，取消正在进行的学习；不改变电机目标 |
| `HSO:Off` | 关闭观测；若已接管则先清零目标、返回编码器 |
| `HSO:Learn` | 编码器带动平稳旋转时，估算磁链；不施加额外辨识电压 |
| `HSO:Motor:Rs,Ls,Flux` | 仅设置 HSO 的相电阻 Ω、相电感 H、永磁磁链 Wb |
| `HSO:Filter:Pole,Delay` | 端电压滤波极点 rad/s、ADC 采样差/PWM 周期 |
| `HSO:Use` | 请求旋转中的 HSO 接管；速度/转矩模式可用，位置模式拒绝 |
| `HSO:Encoder` | 返回编码器并清零目标；保留上次失锁原因 |
| `Stop` | 目标清零，退出 HSO；保留上次失锁原因 |

例如 `HSO:Motor:2.3,0.00086,0.003` 表示 **3 mWb**；最后一个数仅是格式示例，
不能直接当作这台 2804 的实测磁链。`Flux=0` 允许回到等待学习状态。
接管期间拒绝修改观测参数或启动学习；先退出接管。

默认 `HSO:Filter:25000,0.019` 对应当前硬件和 ADC 序列：

- 相端电压：(10k + 10k) / 2k，比例 11；22 nF 在分压下臂，
  `(20k || 2k) * 22nF = 40 us`，极点 **25000 rad/s，约 3979 Hz**。
- `Delay=0.019` 是平均电压采样相对 IU/IV 约 1.9 us 的时差，除以 100 us
  PWM 周期；**不是**上述 40 us 模拟 RC。现有 VV 与 VU/VW 分处不同 rank，
  该值是初始近似，需要结合采样波形校验，不能代表三路完全同时采样。
- VBUS 的 100 nF 不用于上述端电压补偿。

参数目前仅存 RAM，复位丢失。确认磁链后，可将物理 Wb 写入
`mycode/motor_params.c` 的 `MOTOR_2804.psi_f`，重编译形成启动默认值；Rs、Ls
同理。没有更改现有 W25Q64 设置格式。不要把线间电阻/电感直接当相值填写。

## 实现与接管门限

采样使用现有真实端电压，不使用指令电压代替测量。三相端对地电压先经 Clarke
消除共模；电流取同时采样的 IU/IV，IW 用于采样范围检查，避免混入后一个 rank
的电流时间差。电流量程 6.6 A、端电压量程 72.6 V、电频率量程 1000 Hz 是内部
定点归一化尺度，不是允许电流、母线电压或目标速度限值。INA240 + 10 mΩ 的真实
可测双向范围约 ±3.3 A（零点在中点时），不能因为内部量程较大就提高运行电流。

适配层按照 MCSDK 的调用顺序执行 `IMPEDCORR_run` → `HSO_run`；
ST HSO 输入 `Flux_Wb` 直接使用物理 Wb，避免重复除以 2π。官方模板中的
`ratedFlux / (2*pi)` 是其 Flash 参数约定，本工程 `psi_f` 已经是物理磁链。

请求接管前，需累计 2000 个严格合格样本（有效时间约 200 ms）满足：编码器在线且已标定、
电频率 5～400 Hz（上界不含）、电角误差小于 15°、电频率差小于
max(2 Hz, 编码器电频率的 15%)、观测磁链在给定值的 0.5～1.5 倍。
采样序号中断、ADC 电流/电压削顶、参数变更会撤销资格并重置状态。
R16 首次资格允许本节开头所述的有限角度越界暂停，暂停帧不增加进度；其余条件仍须通过。
>=20° 的入场偏差、频率/磁链异常即使同时伴随轻微角度越界，也立即清零，不消耗暂停预算。
通过后，资格保持沿用 R15 的滞回：

| 检查 | 首次资格与 Use 当前帧检查 | 已通过资格后的保持检查 |
| --- | --- | --- |
| 电角误差绝对值 | <15° | <25° |
| 电频率差绝对值 | <max(2 Hz, 编码器电频率的15%) | <max(3 Hz, 编码器电频率的25%) |
| 观测磁链 / 参数磁链 | >0.5 且 <1.5 | >0.4 且 <1.6 |

保持检查连续失败 20 帧（约 2 ms）才撤销资格；恢复一帧完整保持条件会清空此连续计数。
任一保持项目连续失败均计数，即失败项目交替也会累计。尚未取得资格时，只有满足 R16 条件的
有限角度越界会暂停累计，其余失败清空首次计数。
`HSO:Use` 另检查**命令执行时的当前帧**仍满足严格入场门限，避免拿之前的合格状态强行接管。
因此可能暂时显示 TRACKING，但 H Gate 为 ANGLE 等，此时 Use 会拒绝；待 H Gate=OK 再请求。

以下立即撤销资格，不等待 2 ms：角度误差 >=45°；观测与编码器电频率反号，或频差
>=max(10 Hz, 编码器电频率的50%)；磁链 <=0.1 或 >=3 倍；编码器异常；
机械速度换算的电频率不在 [5,400) Hz；非有限数；断帧；ADC 范围错误或采样未就绪；
控制周期 >=100 us；关闭或重设观测参数。

上述保持门限为项目新增的试验策略，非 ST 官方保证的稳定边界；实板仍需校验。
发生真正失锁后先停机并要求新的运动命令，反馈健康时可直接通过新 Speed 在编码器模式启动。
正常低速退出保留目标并继续编码器控制。R19 改为 >45rpm 手动接管、<=45rpm 正常退出，见恢复文档。
角度与速度使用同一个由 ADC 快速环推进的 10 ms 混合系数，速度环不再瞬间更换反馈。

CORDIC 由 `StHso_Init()` 开时钟，ST 数学函数直接设置寄存器，无需修改 .ioc。
只允许 ADC1 ISR 使用该外设。新加的中断或其他计算不要同时操作 CORDIC。
HSO 参数在协议中检查、短临界区排队，在 ADC ISR 中统一应用，避免观测对象并发修改。

## 遥测与诊断

Status 新增：

- `H Gate`：未接管时显示当前严格入场条件的阻塞原因；接管后显示保持条件。
  `OK` 仅表示该帧校验通过，还需看资格累计。
- `H Qual`：例如 `123/200 ms 0/20`，前半为首次资格累计，后半为连续保持失败帧数。
- `H Jitter`：例如 `8/50 0/10`，前半为本次首次资格累计中排除的角度越界帧数，
  后半为连续排除帧数。分别允许最多 50 / 10 帧，超过后重置首次累计和此计数。
- `H Reset`：最近一次因角度失败重置首次资格的有符号电角误差，单位 deg；不是实时角度或峰值。
  重新配置观测器后归零，其他失败不会更新这条角度记录。
- `Feedback`：当前控制反馈 ENCODER / HSO / TO ENCODER / STOPPED。
- `H Lost`：本次 HSO 接管后的首次异常原因，停机和新 Speed 后保留，下一次成功 HSO:Use 清除。
  可能是 ANGLE、FREQUENCY、FLUX、TIMING、SAMPLE、SEQUENCE、ADC RANGE、ENCODER、SPEED、NUMERIC、PARAM、OFF。
- `H Actual`：观测磁链 mWb；原 `H Flux` 为参数磁链 uWb，可对比两者。

不要根据停机后变成 WAIT ADC/SAMPLE 的实时状态判断最初原因，应看锁存的 H Lost。

保留原有 JustFloat 前 16 通道，在 USART1/USB 的 100 Hz 帧后追加 9 个通道。
帧共 **25 个 float + 原 4 字节尾标记 = 104 字节**。上位机需更新通道数量。

| 通道（从 1 开始） | 含义 |
| --- | --- |
| 17 | HSO 电角度 rad |
| 18 | HSO 机械速度 rad/s |
| 19 | 相对编码器电角误差 rad，±π |
| 20 | 观测磁链 Wb |
| 21 | 参数磁链 Wb（学习结果也在此） |
| 22 | 状态：0 OFF / 1 WAIT FLUX / 2 WAIT ADC / 3 OBSERVING / 4 LEARNING / 5 TRACKING / 6 ADC RANGE / 7 LOOP OVERRUN |
| 23 | 整个 ADC 捕获 + HSO + FOC 回调的最大耗时 us |
| 24 | 反馈：0 编码器 / 1 HSO（含返回过渡） / -1 HSO 异常后反馈不健康而阻止驱动 |
| 25 | 最近 HSO 命令：1 接受 / -1 未知命令 / -2 参数错误 / -3 当前不可执行；启动时 0 |

Status 的 H Time 为整个控制回调最大 us / 超过 100 us 的次数；代码也保留适配层
自己的 `max_cycles`。首次参数初始化也计入，未排除“慢样本”。控制回调超时撤销
接管资格；已经接管时零输出停机，后续恢复遵循新命令规则。这些计数必须上板读取，桌面构建无法
证明实际 ISR 耗时。

## 验证范围

最终构建：Debug Flash **113900 B / 131072 B**、RAM **21344 B / 32768 B**；
Release Flash **112580 B**、RAM **21048 B**。两种配置均生成最新 ELF/BIN，
固件版本为 UI-R19-45RPM。保留原有 RAM 函数导致的 RWX 段链接警告。

固件构建真实链接官方 ARM 库。`python tests/motor_host/run.py` 检查真实适配层
的缩放/去共模、磁链估算、断采样/削顶复位、入场 24ms 周期小角度越界、2000 个有效帧才通过、
总计/连续暂停预算、持续角度错误不通过、频率/磁链同时失败不能被角度暂停掩盖、保持滞回/20帧确认、硬故障立即失锁、
角度/速度接管过渡、首次失锁原因锁存和真实协议解析；
桌面测试在 ST 二进制边界使用替身，**不执行 ST ARM 库**，不能验证真实观测精度。
`python tests/ui_host/run.py` 覆盖原有 UI、连按、存储和刷新回归。

仍需上板确认电流/电压波形、相序/极性、Rs/Ls/磁链、PWM 纹波、动态角度误差、
反转行为和真实控制周期。当前约 4 kHz 的端电压 RC 对 10 kHz PWM 抑制有限，
软件按实际 RC 补偿不会消除所有开关纹波；以对比结果决定是否调整硬件/采样时刻。
