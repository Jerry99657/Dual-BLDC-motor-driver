# R73：六步最低速度按 5 rad/s 向上取整

R74 继续使用本页的速度范围，仅优化应用文本格式化；当前固件的 Flash 余量为 2072 B，详见 [R74 用户代码优化](Flash_user_code_R74.md)。下文保留 R73 的构建记录。

2026-10-25，固件 **UI-R73-UI**。最低非零 Speed 指令采用统一规则：

`minimum = ceil((2π × 12 / 极对数) / 5) × 5 rad/s`

| 预设 | 原换算下限 | R73 最低非零指令 |
| --- | ---: | ---: |
| 2804，7 极对 | 约 10.8 rad/s | 15 rad/s |
| 4015，11 极对 | 约 6.9 rad/s | 10 rad/s |

最低值由 `SixStep_MinSpeed()` 统一提供，Run 编辑与控制端准入同步使用；串口提交低于下限的非零 Speed 也会被拒绝。正反方向按相同的幅值边界处理。

最低值按 5 向上进位，后续加减仍使用 Run Steps 的 Speed 步长。例如步长为 0.1 rad/s：

- 2804：`0 → 15.0 → 15.1 → 15.2…`；减少回到 15.0 后，下一步到 0。
- 4015：`0 → 10.0 → 10.1 → 10.2…`；减少回到 10.0 后，下一步到 0。
- 负向对应 `0 → -15.0 → -15.1…` 或 `0 → -10.0 → -10.1…`。零值继续滑行停止，运行中直接反转的限制保留。

物理启动资格仍为 R71 的电频率／电流跟踪／强度／500 ms 稳定及 12 次实际过零，本轮只提高 Speed 指令下限。最低指令值不保证任何负载下都能起转。HSO 的范围、ESC 油门、电流限制和 Speed 上限未调整；Speed Limit 低于最低非零值时，Run 保持 0 并提示提高 Speed Limit。

源码使用等价整数表达式 `(15 / poles + 1) × 5`，适用于参数表中合法的正整数极对数：`2π×12/5` 严格位于 15 和 16 之间。这样保持同一取整规则，同时避免增加 Flash 占用。

`tests/motor_host/run.py`、`tests/ui_host/run.py` 全部通过，新增控制端正反向边界接受／拒绝，以及两套预设的 0→最低值→0.1 步进→0 的实际 UI 测试。原 FOC、HSO、双机、六步模型、保护、编码器、存储、按键与 LCD 回归通过。Debug／Release 构建、强初始化／中断检查、ELF/BIN 一致性检查通过；尚未烧录实板。
