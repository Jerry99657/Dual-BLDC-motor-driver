# R89：ESC 通用六步自适应起转

固件 `UI-R89-ESC`。本轮针对 ESC Auto 固定 0.25 A 起转、4015 持续单向转动却报 `6STEP START TIME` 的问题，调整启动电流包络及允许升频速度。保留原有功能，CubeMX、ST 官方源码和编译选项均无需改变。

## 先复现，再修改

旧程序在 ALIGN 后以固定电流目标和固定 20 电气 Hz/s 升频。即使油门设为 75%，I/F 启动目标仍为 0.25 A；油门在真实过零接管后才参与输出。I/F 的电流跟踪条件不满足就清空连续 500 ms 的交接资格，因此“在转”与“能够进入 SYNC”并不是同一条件。

将用户测得的 4015 等效参数 `R=1.92 Ω、Ls=440 μH、磁链=9.29 mWb、极对数=11` 放入独立 RL／PMSM 模型，包含 PWM、续流、40 μs 电压 RC、ADC 错时和电流量化。模型转子由电流产生转矩后积分得到，不被直接设为控制参考。控制器的 ESC 路径没有读取这些电机参数。

| 同一模型的测试组合 | R88 | R89 |
| --- | --- | --- |
| 12 V，30%／75%，三组惯量 | 6/6 进入 RUN | 6/6 进入 RUN |
| 20 V，30%／75%，三组惯量 | 0/6，START TIME | 6/6 进入 RUN |

惯量为假设的 `2e-5、4e-5、8e-5 kg·m²`，并非实测。旧版 20 V 时模型持续同向转动约 8.4 rad/s，却反复丢失 Hold；新版捕获时启动电流目标约 0.287～0.299 A，通过完整 Hold 和真实过零后进入 RUN。这个反例证明旧逻辑存在脆弱条件，不能证明实板所有失败均由同一原因造成；用户本次测试的母线电压尚未提供。

## 新启动流程

`静止资格 → ALIGN → 自适应 I/F SINE → SYNC（真实过零）→ RUN`

- ALIGN 保留 1 s；电流从零在 400 ms 内升到 0.25 A。
- ESC 的 SINE 启动电流目标从 0.25 A 起，在有电压余量、交接资格未连续保持 100 ms 时，以约 0.05 A/s 增加，最多 0.5 A。达到连续 100 ms 后冻结电流幅值；资格被打断时可继续有限提升。
- 电流跟踪不佳或调制度达到 0.7 时暂停升频；恢复后允许以 20 电气 Hz/s 升频。电压余量不足时也停止增加电流目标。频率连续，不跳到高频强拖。
- 原有最低 12 电气 Hz、最高 60 电气 Hz、强度检查及完整连续 500 ms 交接资格保留。达到捕获条件时仍可保持频率，因此“允许升频 20”不表示频率始终在增加。
- SYNC 的滤波相电流软上限与启动目标协调：`min(0.5 A, 1.2 × 启动目标)`，避免启动增强后在交接瞬间被原 0.3 A 上限截断。RUN 的滤波相电流软上限仍为 0.5 A。
- 必须收到 12 次合格的真实悬空相过零，才打开 RUN 油门控制。保留相位／周期检查、30° 换相定时、丢过零停机和 8 s 总启动超时，不通过定时盲换相冒充成功。

上述 0.25～0.5 A 是启动旋转电流矢量的目标幅值，RUN 的 0.5 A 是滤波后的软限制，均不是每个瞬间相电流的硬阈值。PWM 纹波和交接瞬态可能超过目标幅值。

电流误差用于判断电流跟踪和纹波，**不是转子速度／负载观测器**。`Start EMF` 沿用滤波后的实际 q 轴电压强度代理，含电感等贡献，不是纯反电动势测量。I/F 的 Ref 是施加的频率，不是真实转速。真实运动及换相最终由 SYNC 的相电压过零验证。

仅 ESC Auto 启用上述自适应。2804／4015 预设仍保留原启动电流及 20 Hz/s 升频规则、Speed／Throttle 和速度范围。ESC 继续只支持 Throttle、电气 Hz，不要求 Rs／Ls／极对数输入，也不宣称可以驱动任意参数或任意负载的电机。

## 保护与诊断

三相电流采样、ADC 有效性检查、ESC 原有 2 A 瞬时相电流阈值、0.8 A 基准的过载积分预算、M1 IBUS 比较器硬件 Break、KEY1 全局停止继续工作。没有提高硬件或瞬时过流门限，也没有屏蔽保护。故障后保持停止，必须由用户显式重新启动。

Status → Six Step 新增：

| 行 | 含义 |
| --- | --- |
| `6S Start I` | 本次 I/F 启动电流目标；不是瞬时测得电流 |
| `6S Ramp Hz/s` | 电流跟踪／电压余量控制器允许的升频率，0 或 20；达到捕获频率仍会保持频率，退出 I/F 后保留末值 |

`6S Hold` 仍显示毫秒。内部改为只累计 10 kHz 采样计数，在快照出口换算毫秒，减少快中断中的除法和重复存储。电脑控制台诊断可读取新行；无需增加常态遥测通道。

电脑端仍为单个 `pc_tool/index.html`，更新为 R89，兼容 R88 的完整功能及 R87 的原优先功能。schema 2、92 B 配置回执、全部 12 类遥测、设置保存格式及 USB／USART 速率均保持。
