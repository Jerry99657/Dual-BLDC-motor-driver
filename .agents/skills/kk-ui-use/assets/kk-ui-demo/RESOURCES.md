# 标准 Demo 资源来源

本目录中的应用与资源为可编辑项目副本。运行时不捆绑完整中文字库。

| 资源 | 来源与参数 |
|---|---|
| 应用与项目图标 | KK_UI 开发仓库正式参考应用；四个 32×32、1 bit XBM 图标，合计 512 B |
| 首页字模 | LEDFont Agent API v1，`wenquanyi_13px`，字号 14 |
| 标题字模 | LEDFont Agent API v1，`wenquanyi_9pt`，字号 12 |
| 正文字模 | LEDFont Agent API v1，`wenquanyi_13px`，字号 14 |

2026-09-19 完整读取 LEDFont 官方 Agent API 说明，查询实时目录后按当前界面文字重新生成标题和正文完整子集；首页文字未变，复用原字模。只提交界面字符集与字体、字号、数组名参数。三个字模的字符、码点、字形数量、实际字节数和返回变体记录在 `font-resources.json`。首页 11 字形 / 394 B、标题 30 字形 / 635 B、正文 148 字形 / 3902 B；返回字符集与请求一致，无缺字。

动态字符包含完整十进制数字、FPS、状态、单位、逻辑尺寸和三种刷新模式文本。配套字模支持已确定的 Demo 文字；文字、动态字符或字号变化后重新检查并生成所需子集。保持文字和字号时可直接复用，不要求目标工程再次访问在线字体服务。

第一方应用、图标和 KK_UI 代码采用随包提供的 MIT 许可证。在线服务此次没有返回字体许可声明；第三方字体不因采用 KK_UI 而转为 MIT，此处不推断其许可。字体来源为 <https://ledfont.botelvdong.com/agent-api.md>。
