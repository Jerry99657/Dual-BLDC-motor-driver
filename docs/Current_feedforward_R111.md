# R111：电流环前馈与饱和处理

固件标识 `UI-R111-CUR`，Native 回执版本 111。存储格式、协议结构、通道定义和 UI 操作不变，上位机版本兼容范围同步扩展。没有新增必须在 CubeMX 中配置的外设或参数。

## 两轴共用电流控制路径

`JerryFOC_CurrentControl()` 供 M1、M2 的 10 kHz 电流环共用。它读取该轴当前已应用的电机参数，计算：

\[
\omega_e=p\omega_m,\quad
U_{q,req}=PI_q+g\omega_e(\psi_f+L_s I_d),\quad
U_{d,req}=PI_d-g\omega_e L_s I_q
\]

机械速度单位为 rad/s，带方向；`Id/Iq` 为当前反馈电流。当前等效模型采用 `Ld=Lq=Ls`。公式采用项目既有 Park／逆 Park 符号，与 [PMSM 前馈解耦公式](https://www.mathworks.com/help/mcb/ref/pmsmfeedforwardcontrol.html) 一致。PI 继续补偿电阻压降、模型误差和动态误差；本轮没有额外加入 Rs×目标电流前馈，没有修改原 Kp／Ki、速度环或位置／主从调校。

- 编码器模式：使用该轴已滤波的实际机械速度，不使用 Speed 目标值。M1、M2 分别读取自己的参数和反馈状态。
- `g` 在电流环启用后约 50 ms 从 0 增至 1；停机、控制器复位、型号／参数重载时归零，避免初次启用突然施加完整前馈。
- 出厂 2804／4015 的磁链仍为 0，代表未知。此时不生成永磁反电动势项，保留 Ls 解耦和 PI；应用有效辨识结果或选择带有效结果的 Custom 型号后，自动使用其磁链。参数保存／应用方式沿用现有界面。
- 当前电流目标及 Id/Iq 矢量电流限制继续由原调用路径执行，额定持续目标、峰值停机门限和累计过载保护未放宽。

例如已应用的 4015 参数为 11 极对、9290 µWb，实际转速 40 rad/s、Id≈0 时，满幅 q 轴反电动势前馈约 4.0876 V；最终电压仍由母线限幅约束。

## HSO 使用独立观测器模型

用户适配层新增 `StHso_FeedforwardModel()`，提供当前活动观测器的 Ls、磁链及用于前馈的电气速度。它读取 HSO 已装载／学习的参数，不读取编码器，也不要求把 HSO 本次学习的磁链先复制到电机预设中。

I/F 对齐、升频、磁链学习、CAPTURE 均不加入该前馈。进入 CONTROL 后，前 50 ms 保持关闭，等待既有坐标系旋转接管完成；随后约 50 ms 平滑加入。停止或观测失效时不输出前馈速度。原 I/F 电流矢量交接、资格判定、最低速度、故障停机和手动重新启动规则保留，ST HSO 二进制及官方源码未修改。

## 总请求限幅与积分回算

旧电流 PI 在输出处先独立截断 P+I，会隐藏一部分饱和量。现在保留完整 PI 输出，加入前馈后再进行一次 dq 矢量限幅：

\[
\sqrt{U_d^2+U_q^2}\leq
0.95\frac{\min(VBUS,V_{motor,max})}{\sqrt{3}}
\]

沿用原来的实测 VBUS 缩放、型号电压上限、SVPWM 和 5% 裕量。PI 积分仍有原来的有界限制；回算系数沿用 0.2，以调制器返回的估算施加电压减去完整的 `PI+FF` 请求进行修正，两个轴采用相同路径。

返回电压由最终浮点占空比估算，并非相电压 ADC 的实测值；死区、器件压降及 PWM 计数量化仍会形成模型误差，由反馈 PI 处理。本轮没有宣称补偿这些误差。

补充拒绝非有限母线电压，避免 NaN／Inf 占空比写入定时器。非有限电流 PI 请求产生中性 PWM，并清除被污染的积分状态；既有硬件 Break、KEY1 全局停止、ADC／编码器保护和输出门控继续有效。专用 Stop 仍先关闭输出，不能把中性 PWM 等同于滑行停止。

普通电压模式继续把命令按 V 处理，不叠加本轮前馈；纯开环、对齐电压、六步换向和参数辨识保留各自路径。

## 验证与资源

新增 `tests/motor_host/test_current.c`，验证真实 PI、前馈、参数装载及 PWM：两轴、正反转、不同电角度、12／20 V、不同已应用 Ls／磁链、反馈速度与目标速度区分、启用渐入、参数未知退化、总矢量限幅、未截断请求的积分回算，以及非有限输入后的恢复。

独立 RL＋dq 反电动势模型包含电流低通、规定的正反速度变化、母线跌落／恢复、制动及零电流目标。四组测试的电流峰值约 0.415 A，指定稳定检查点的 dq 电流误差小于 0.001 A。这只是参数匹配模型下的软件结果，不代表实板性能或保护认证。

真实 M1、M2 调用路径均验证：编码器电流模式使用各轴参数和实际速度，电压模式仍直接输出电压；M1 Stop 清除渐入状态。HSO 适配器验证活动参数、独立学习、双方向电气速度、I/F／坐标系旋转期间关闭和渐入时序；专有 HSO 二进制在主机测试中使用桩，实板算法效果仍需复核。

完整电机回归、编码器／采样／保护、双机主从模型、HSO 独立启动、六步模型、辨识、协议、USB／USART Native／JustFloat、UI／设置服务及上位机真实浏览器流程通过。43 项 CubeMX 配置变更回归及两个实际 ARM 镜像的启动／MSP／保护路径检查通过。
