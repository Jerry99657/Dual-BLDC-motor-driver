# R105：三个独立电机槽位

固件 `UI-R105-MOT`，保留 `Apply M1/M2` 和 `Preset M1/M2`。新增 `Custom 1/2/3`，两轴共用这三个电机定义，每轴可独立选择。无需更改 CubeMX。

## 板端使用

1. 先选择合适的 2804／4015 基础型号，完成 M1 的极对数、Rs、Ls、磁链辨识；也可使用 R104 已保存的完整结果。
2. 在辨识结果页左右切换至 `Save Custom 1`、`Save Custom 2` 或 `Save Custom 3`，按 OK。当前新辨识结果会一并保存；保存槽位不会自动切换电机或发出 Run 指令。
3. 等待 `Saved` 后再断电。在 Settings → Motor 中，已有有效参数的 Custom 才会出现，空槽隐藏。选择目标轴和 Custom 后，按原规则重新对齐，再手动运行。

槽位保存极对数、等效星形 Rs／Ls、磁链和辨识来源型号。电流 PI 按电参重算；其余控制参数、相电流／过载阈值、电压／速度上限继承辨识来源的基础型号，不会根据测试电流推算额定电流。IBUS 硬件阈值仍使用 Settings 的全局配置。M1 使用测得的方向，M2 保留其基础型号原有的编码器方向。

保存要求完整有效的测量记录、Flash 可用、两轴停止，没有对齐／辨识／联动运行；两个轴都不能仍选择准备覆盖的槽位。覆盖前先将两轴切到其他型号。无效／拒绝操作不会修改原槽位或发出运动请求。

与其他 Settings 一样，受理保存后先更新 RAM 并显示待保存状态，菜单此时可以选择有效记录；实际掉电持久化以 `Saved` 为准。写入失败会继续显示保存错误，不能把 `Save queued` 当作已经写入 W25Q64。

## 原有 Apply／Preset

`Apply M1/M2` 继续将保存的辨识结果应用到该轴当前的 2804／4015 配置；`Preset M1/M2` 恢复该轴当前基础型号的预设电参。这两个动作仍要求停止、编码器模式和目标编码器健康。

Custom 与两个轴的应用记录相互独立。保存／覆盖 Custom 不会改变 2804／4015 的已有应用记录；切回 4015 时，若此前曾 Apply 4015，仍使用那份应用记录。需要纯程序预设时，先选择 4015，再执行该轴的 Preset。Custom 被选中时应通过 Motor 切换型号，Apply／Preset 不会隐式改写共享 Custom。

每个 Custom 可覆盖更新；恢复全部默认设置会清空三个槽位和旧应用记录。仅进行新一次辨识、保存普通结果或 Apply，不会自行更新已保存的 Custom。

## 上位机与存储

单 HTML 的辨识面板提供槽位选择和“将已保存结果存入槽位”。先保存完整结果，再执行槽位保存。型号列表只追加有效槽位，工作模式／驱动／Run 联动保留，M2 仍仅有感 FOC。保存不会自动运行，覆盖有明确确认。

| 功能 | 命令 |
| --- | --- |
| 保存已存测量结果到第 n 槽 | `App:0,20,n`，n = 1～3 |
| M1／M2 选择自定义电机 | `Motor1:Custom1`／`Motor2:Custom1`，末尾也可为 2、3 |
| 查询配置及槽位可用状态 | `Get` |
| 查询当前轴实际 Rs／Ls／磁链 | `GetRow:1,0,15`，另一轴使用 2 |

配置包仍为 schema 2、92 B 载荷，JustFloat 通道不变。`control_config[25:24]`、`[27:26]` 分别保存两轴的 Custom 槽编号，0 表示基础型号；回执专用 `[30:28]` 为三个槽位的有效位，不写入设置。基础型号仍保存在原有位中。诊断型号 ID 保留 0＝2804、1＝4015、2＝ESC，3～5 对应 Custom 1～3。

设置版本升至 v7，160 B，仍在同一 W25Q64 A/B 日志区内单页写入并校验。v6 的测量结果、来源标记及两轴应用记录均保留；v1～v5 按原规则迁移，未绑定来源的旧结果不能创建 Custom。无效／缺失槽位会隐藏，上电时若选择指向该槽，会回退到其基础型号。

设置 JSON 可引用本板已有的 Custom，缺失槽位会拒绝导入。JSON 不携带槽位的辨识数据，不用于在板间复制电机定义；导入仍保持全局停止，运行前需核对电机与参数。
