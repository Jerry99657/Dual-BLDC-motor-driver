# 单 HTML 控制效果测量

本功能在 `pc_tool/index.html` 内处理已有遥测，把曲线转换为可重复比较的指标。适用于速度／位置阶跃、主从跟踪和指定频率的往复运动。没有增加板端通道、命令或算法，不占 MCU Flash／RAM，也不需要调整 CubeMX。

## 1. 入口与基本操作

1. 用桌面 Chrome／Edge 打开 `pc_tool/index.html`，连接 USB CDC 或 USART。沿用原有 Native-first 握手。
2. 通过原有 Run 面板操作电机，或载入此前保存的原始曲线 CSV。测量面板自身不发送运动指令。
3. 点击导航“效果测量”，选择通道预设和分析方式。
4. 在曲线中选择画布、拖动／缩放到目标区间，再点击“取当前画布视窗”。也可直接填写起止板端秒数。即使曲线使用相对时间显示，这里的输入仍是板端绝对秒数。
5. 点击“分析该区间”。分析使用点击时的数据副本，实时接收和绘图继续。分析完成后的结果固定，不随新数据改写。
6. 点击“保留为对比”留下本次摘要；改变工况后重新分析，可并排比较最多 6 项。导出测量 JSON 或指标 CSV 保存结果。

起止输入都留空时，分析自动取当前画布视窗；只填一项会提示补齐。选择实时画布时，可用其数据源中的全部现有通道；选择暂停画布时，只能分析暂停前已加入该画布并保存的通道。暂停画布的数据不会被后续实时采样替换。

测量名称在点击分析时一并记录。分析之后再改名称不会改写旧结果，需重新分析。清空曲线、换采集组或切换数据来源后，旧摘要继续保留并提示数据已换段。

## 2. 通道预设

| 预设 | 参考 | 反馈 | 单位 |
| --- | --- | --- | --- |
| M1／M2 速度 | `mN.target_speed` | `mN.feedback_speed` | rad/s |
| M1／M2 位置 | `mN.target_position` | `mN.position` | rad |
| M2 主机 → M1 从机 | 从轴位置 − `group.error` | `m1.position` | rad |
| M1 主机 → M2 从机 | 从轴位置 − `group.error` | `m2.position` | rad |
| M1 HSO 速度 | `m1.target_speed` | `hso.control_speed` | rad/s |
| M1 六步 Speed | `six.target` | `six.estimated_speed` | rad/s |
| 自选通道 | 用户选择 | 用户选择 | 必须相同 |

板端主从误差定义是 **从轴实际位置 − 最终目标位置**，因此工具使用同一帧的从轴位置减去 `group.error` 还原最终目标。这包含板端已经处理的零点、比例和方向；不会把主轴原始绝对位置直接当作从轴目标。误差与从轴位置必须有相同时间戳，缺失时不跨帧插值制造目标。

所有统计统一采用 **误差 = 反馈 − 参考**。参考与反馈不能是同一通道，且必须同单位；不允许把油门百分比与机械速度直接相减。六步 Throttle／ESC 的电气 Hz 不适用机械 Speed 预设，可使用自选同单位通道作有明确物理意义的比较。

HSO、六步专题数据需先通过现有采集组选择功能取得对应通道；测量预设不会擅自更改板端采集组。没有该通道时会明确提示缺少采样。

## 3. 跟踪误差统计

适用于任意连续参考，包括手转 Follow、速度变化和稳态波动。时间区间不必包含阶跃。

| 指标 | 含义 |
| --- | --- |
| RMS 误差 | 误差平方积分的时间平均再开方，反映整体偏差 |
| 峰值绝对误差 | 有效成对采样中最大的绝对误差 |
| 平均误差 | 带符号的时间平均；正值表示反馈平均偏大 |
| 误差标准差 | 去掉平均偏差后的波动，按时间加权 |
| IAE | 绝对误差积分，单位为通道单位 × 秒 |
| 有效时间覆盖 | 有效积分时长 ÷ 请求区间时长 |
| Iq／VBUS | 同区间有这些通道时附带遥测 `|Iq|` 峰值、母线最小／最大值 |

设相邻有效误差为 `e0、e1`、时间差为 `dt`，积分采用梯形累加：

```text
误差积分   += dt × (e0 + e1) / 2
平方积分   += dt × (e0² + e1²) / 2
绝对值积分 += dt × (|e0| + |e1|) / 2
RMS = sqrt(平方积分 / 有效积分时长)
```

标准差使用时间加权的稳定方差更新，避免大直流偏置下两个大数相减造成精度损失。IAE 受观察时长影响，只能在相同时长、单位和工况下直接比较。跟踪误差不对参考或反馈做延迟补偿。

## 4. 单次阶跃响应

选择包含“阶跃前稳态 + 一次目标跳变 + 阶跃后响应”的区间。工具支持正向和负向阶跃，输出：

- 10% 响应延迟：从采样目标跳变到反馈达到阶跃幅值 10%。
- 10–90% 上升时间：反馈从 10% 到 90% 所需时间。
- 到达 90% 的总时间。
- 超调：沿阶跃方向越过最终目标的最大量 ÷ 阶跃幅值。
- 稳定时间：进入容差带，并在剩余观察区间持续处于带内且达到最短保持时长。

默认相对容差 2%、绝对容差 0、最短保持 0.2 s。实际容差带取 `max(|阶跃幅值| × 相对容差, 绝对容差)`。可以按电机噪声和位置精度要求调整。

为避免给不合适的数据制造数字，阶跃分析有以下条件：

- 阶跃前后至少各 3 个样本，前置基线至少 20 ms。
- 前置反馈须接近参考且已稳定；前后参考须近似平台，平台允许误差为幅值的 1%。
- 最大单次跳变量须占整体阶跃幅值至少 80%；斜坡、多个目标或明显周期参考不报告单次阶跃指标。
- 区间不能包含无效点或超过用户设置的最大采样间隔。

阈值交点在相邻采样之间线性估计；目标变化时刻取首个变化样本。未到 90%、未稳定，或末尾带内观察时间不足时显示“未确认”，不会填成 0。稳定时间只证明剩余已观察区间内的表现，不保证未来不会再次越界。阶跃分类失败时，已有的普通跟踪统计仍可显示。

## 5. 指定频率往复分析

用于比较类似“±10°、每秒往复 4 次”的跟随表现。选择包含稳定往复运动的区间，在“容差、采样与往复频率”中输入实际基频，例如 4 Hz。

参考与反馈分别拟合：

```text
x(t) = c0 + a × sin(2πft) + b × cos(2πft)
幅值 A = sqrt(a² + b²)
相位 φ = atan2(b, a)
幅值比 = A反馈 / A参考
相位滞后 = wrap(φ参考 − φ反馈)，范围 ±180°
相位折合滞后 = 相位滞后 / (360° × f)
```

拟合采用时间加权最小二乘，并先扣除起始偏置以减轻大累计机械角度的数值影响。结果包含两个基波幅值、幅值比、相位滞后、折合时间和拟合 R²。

- 正相位差表示反馈滞后，负值表示超前。
- 需要至少 3 周期时长，且最差相邻采样间隔也满足每周期至少 10 点。
- 区间须连续；参考 R² 至少 0.8、反馈 R² 至少 0.5，参考激励不能接近零。
- 输入频率与实际运动不符、手转节奏明显变化或数据质量不足时，会解释原因并不报告幅相。
- 折合时间存在整周期歧义，不是唯一的通讯延迟；本功能不是完整闭环扫频／带宽辨识。

4 Hz 的建议观察区间至少 0.75 s，实际宜取数秒稳定运动；至少需要 40 Hz 的真实采样。改变输入框频率只改变分析，不会让电机自动往复。

## 6. 数据对齐、工况与限制

### 采样对齐

以参考通道的采样时刻为基准。优先使用同时间反馈；非主从推导时，允许在两个有限反馈点之间线性插值。默认最大采样／插值间隔为 0.1 s，可按实际遥测速率调整。不外推，不越过无效点，也不把长时间丢包补成连续数据。

统计使用真实时间权重，适用于不均匀采样。NaN 和过长间隔不进入积分；覆盖不足 95% 会提示。时间回退或重复时刻会拒绝分析，需重新载入单一时间段或清空采样。不同板端 epoch／采集组沿用原有曲线换段机制，不混算。

### 工况记录

摘要记录名称、捕获时间、来源、画布、epoch、采集组、通道、区间、分析设置、最近已知控制模式与可用的 Iq／VBUS 摘要。

收到状态时，工具记录工作模式、反馈驱动、两轴控制模式和电流环状态的变化。分析区间跨越已记录的这些变化会被拒绝；主从预设还会检查已知主从方向。没有元数据的旧 CSV 可分析，但会提示人工确认工况。

JSON 中可包含分析时最近读回的板端设置。这不是逐采样配置历史，不能证明整段型号、限幅或增益均未变化；应在每次调参后重新读回、记录并分别取区间。CSV 回放只使用文件中记录的状态，不借用当前在线板端的设置。状态采样本身有间隔，不能精确定位两次状态帧之间的配置切换。

### 测量分辨率

时间指标来自板端遥测时间戳及采样间隔，不包含精确 USB／USART 发令延迟。屏幕上的 Iq 峰值是低速遥测峰值，不是 PWM 周期瞬时峰值，不能用于替代相电流保护或硬件示波器检查。亚采样间隔的交点是插值结果，不增加实际测量带宽。

离线演示的结果明确标为模拟。不同单位、参考幅值、供电、负载或观察时长只并列展示，不自动判定哪个参数更优。

### 资源与交互

单次分析每通道最多 100000 个原始点，不以降采样绕过上限。原始输入副本和对齐工作数组计入现有共享 128 MiB 类型数组缓冲预算；超出预算会提示缩短区间或释放暂停快照。分析完成／取消后释放工作缓冲，只保留摘要。

计算分块让出浏览器事件循环，可取消，采样、曲线和全局 Stop 继续处理。分析中切换数据来源或清空数据会取消旧任务；失败与取消不覆盖上一份已完成结果。对比摘要只保存在当前页面，重载前请导出。

## 7. 导出

- **测量 JSON**：`FOC-control-measurement-report` version 1，含保留的对比项和当前项。每项包含 `meta`、`options`、`result`，保留指标有效性、拒绝原因、质量与工况说明。
- **指标 CSV**：每行一个摘要，包含误差、阶跃、幅相、Iq／VBUS、时间范围、容差与质量说明；未确认指标留空。字符串按 CSV 规则转义，并处理可能被表格软件识别为公式的前缀。
- 原始波形继续使用原有“记录 CSV”。摘要导出不包含完整采样数组，不能代替原始记录；测量摘要 CSV 也不是曲线回放文件。

若当前项已经保留为对比，导出会同时含已保留项和当前项，便于区分历史列表与本次结果。
