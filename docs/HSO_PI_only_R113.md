# R113：撤回 HSO 电压前馈

固件 `UI-R113-HPI`，Native 配置回执版本 113。针对加入前馈后 HSO CONTROL 出现明显震动的报告，撤回 R111／R112 在 HSO 路径上增加的模型电压补偿。此前主机回归不能证明该补偿适用于本板的实际 HSO 控制，本轮优先恢复纯 PI 路径，不继续调整前馈渐入时机。

## 变更

- M1 选择 HSO 时，启动、磁链学习、CAPTURE 和 CONTROL 的电压均来自 d/q 电流 PI，不叠加永磁反电动势前馈或电感解耦前馈。
- 移除 `StHso_FeedforwardModel()` 声明、实现及全部代码引用，没有延时自动重新启用入口，也不新增设置开关。
- HSO 路径将前馈增益保持为 0，不向 PI 积分转移模型电压。即使存在残留的编码器模式增益，也不会引入补偿或改写积分来平衡它。
- 编码器模式保留已应用参数对应的前馈、无扰增益启用、两轴独立状态和现有电流目标限制。
- 原 HSO I/F 启动、电流矢量接管、速度环、参数学习及相电压／电流观测仍保留；Curr Loop 在 HSO 中继续强制 ON。关闭本轮前馈不等于关闭电流环，也不等于关闭观测器所需的电压采样。
- 继续保留实时 VBUS 与型号电压上限、dq 矢量限幅、第 4 批未预截断总请求的积分回算和非有限输入处理；原 Kp／Ki 不变。过流、过载、ADC、HSO、编码器、100 µs 时限、Break、KEY1 与显式重新启动保护未放宽。
- R112 的 CONTROL 故障记录（H Reject、H R EMF% 等）继续保留。

协议布局、存储版本、保存参数和 UI 操作不变；单 HTML 上位机兼容范围同步到 113。无需修改 CubeMX、清空 W25Q64 或重新辨识电机来停用 HSO 前馈。

## 验证

新增真实 HSO 适配器＋FOC 调用路径回归，先在 R112 运行并按预期失败：进入 CONTROL 超过 150 ms 后前馈增益仍会升高。R113 在该时间之后仍保持增益 0；编码器始终断开，独立起转／CONTROL、故障停机、KEY1 和手动恢复测试通过。

另用真实电流控制函数验证 HSO 纯 PI 输出：更改传入模型速度（含正／负／NaN）、设置残留前馈增益，保持电流误差为零，PI 电压和积分不受模型电压影响。

3000 点正常电流轨迹按 R110 的电流 PI 算式独立计算，对照 R113 的 PWM／积分状态，在 6／12／20 V 和最终电压矢量限幅下逐点一致。这项对照的分量 PI 预截断未触发；大误差分量饱和仍采用第 4 批的完整请求积分回算，不能据此称整个电流控制在所有异常输入下完全回退为 R110。

编码器前馈、无扰切换、独立 RL／dq 模型、总请求饱和、非有限输入恢复、双机／主从、六步、辨识、采样／编码器保护、协议及双通信格式的完整主机回归通过。UI／设置、HTML 控制台与真实浏览器、43 项 CubeMX 配置变更及两个实际 ARM 镜像启动检查通过。

## 实板验证反馈：2026-10-29

用户确认：“R113 新版已验证，运行平稳”，并决定保留。R113 作为当前 HSO 稳定基线，取消此前讨论但尚未写入的 R110 回退。

保留的控制方案为：HSO 全程纯 PI 电流控制，采用 R113 的电压矢量限幅及积分回算；编码器模式保留前馈和无扰切换。HSO 模型电压前馈继续移除。

反馈来源为用户实板测试；本次未另行记录电压、速度、负载和持续时间。本次仅更新验证记录，固件源码、版本、构建产物及已保存设置均保持 R113。
