当前扩展版为 **UI-R79-ID**：在 R78 跨零修复基础上增加 Ls、磁链与 Ke；新流程及翻页操作见 [R79](Motor_detect_R79.md)。下文保留 R77／R78 历史行为。

当前固件已更新为 **UI-R78-ID**，修复 POLES 扫角时近零短暂全零帧导致中止的问题。检测入口和流程沿用下文；新增判据、验证及当前固件占用见 [R78 跨零修复](Motor_detect_zero_gap_R78.md)。下文 R77 占用和校验值保留为历史记录。

固件 **UI-R77-ID**，2026-10-25。新增 `Settings → Motor → M1 Detect`，检测 M1 的极对数与 FOC 等效相电阻，结果单独保存到 W25Q64。当前运行仍使用选择的 2804／4015 预设；检测结果不自动替换预设、保护阈值或 HSO 参数。本批不辨识电感、磁链或额定电流。

## 操作

1. 选择 **Single M1**，关闭 HSO Feedback 和 Six Step，保持 ENC1 正常，等待原有上电对齐完成并停止输出。其他工作模式下检测菜单禁用。
2. 电机空载，转轴可自由转动。进入 `Settings → Motor → M1 Detect`。
3. 上／下调节 `I test`，范围 **100～500 mA**、步长 **50 mA**，默认 **300 mA**。这是检测电流目标，原有软件过流及 COMP4 硬件保护仍然生效。
4. 按 OK 开始：`RS LOW → RS HIGH → POLES + → POLES - → DONE`。完整流程约 **35.7 秒**。两档电阻检测各 0.8 秒，正反向各转 32 个电周期并保持 0.3 秒。因此 2804 每个方向约转 4.57 机械圈，4015 约 2.91 圈。
5. 结束时自动关闭输出。`PP 11+ R 1.80 ohm` 表示 11 极对、Rs 约 1.80 Ω；极对数后的正负号表示 ENC1 计数相对于正向测试电角度的方向。
6. DONE 后按 OK 排队保存，等待 `Saved` 提示；写入失败沿用原 Save 故障提示。左右键清空本次草稿以重新检测；重新进入时，已保存的结果标为 `Saved`，按 OK 才开始新检测。

检测中 OK 停止，KEY2 停止并返回，KEY1 全局停止。取消或故障不会保存半成品，也不会自动重试或重启电机。运行中的电流目标不能通过方向键改变。

## 方法与边界

电阻检测在固定定子方向上，通过独立的低带宽电流调节器注入半档、全档测试电流；每档先稳定 0.6 秒，再平均 0.2 秒。采用 `Rs ≈ ΔUd / ΔId`，要求电流持续接近目标且机械位置保持稳定，再检查结果及两档电流间隔。该调节器不读取预设 Rs、Ls 或极对数，普通 Run 的 Curr Loop 偏好保留。

电压采用现有调制器根据最终占空比、实时 VBUS 反算的周期平均**指令电压**。当前谷底相电压单点受到 PWM 与约 40 μs RC 的影响，不能直接作为稳态平均电压。两档差值可减小同一电流极性下固定压降的影响，但结果仍可能包含功率管、死区、采样电阻、线缆和电流增益误差；这是板上估算，首次实测应与线间电阻比较，不能把理想模型精度当作实物精度。

Rs 的口径是等效星形、线对中性点电阻；对称三相电机的线间电阻约为 **2 × Rs**。4015 三角形绕组的 3.6 Ω 线间电阻对应 Rs 约 1.8 Ω，而不是其 5.4 Ω 单支路电阻。[TI 参数定义](https://www.ti.com.cn/cn/lit/ug/zhcubu7c/zhcubu7c.pdf)

电阻结果校验范围 0.1～50 Ω，实际可测范围还受到测试电流及 `min(4 V, VBUS × 20%)` 注入电压上限限制；无法建立稳定电流时拒绝结果。本版优先面向现有两台欧姆级云台电机，尚未验证毫欧级、低电感电机。

极对数检测直接使用 MT6701 的 14 位原始机械角计数，解绕回后计算 `p ≈ 32 × 16384 / |Δcount|`，范围 **1～32**。每方向至少覆盖一整机械圈，降低局部编码器非线性与磁铁偏心造成的比例误差；另外检查中点位移、整数接近程度、正反方向和重复性。失步、磁铁安装误差过大或机械干涉仍可能使检测失败。[ST 也要求机械转数参考辅助检测极对数](https://wiki.st.com/stm32mcu/wiki/STM32MotorControl%3ASTM32_MC_Motor_Pilot_-_Start-up_guide)。本模块为项目自己的实现，不是 ST Motor Profiler 的移植。

## 故障与集成

| 提示 | 含义 |
| --- | --- |
| Stop/check encoder | 启动准入失败，检查工作模式、输出、编码器、对齐、ADC／母线及停止按键 |
| RS NOT STEADY | 测量窗口内电流未稳定到目标，或转轴仍移动 |
| RS RANGE | 电阻结果不合理或两档电流差不足 |
| POLES / SLIP | 没有有效旋转、中点不一致或结果不接近整数 |
| POLES / REPEAT | 正反向结果、方向或位移一致性检查失败 |
| E1 JUMP／ENCODER1 LOST | 编码器出现不合理单步跳变或失联 |
| CURRENT | 检测电流过大、三相电流和异常或非有限值 |
| ADC SEQ | 注入采样帧序号不连续 |

其他 ADC、VBUS、VREFINT、过流、过载及 IBUS 故障保留原原因。检测复用现有 5 ms ADC／母线看门狗；正常运行的控制循环在检测期间让出 M1，检测期间拒绝新的 Run、OpenLoop、工作模式和型号切换命令。主机模型同时运行真实 10 kHz ADC 调度和 1 kHz 外环，验证外环不会覆盖检测输出。

结果增加一个 32 位设置字段：低字节保存带方向的极对数，bits[23:8] 保存毫欧单位 Rs。设置格式升为 **v4**，自动迁移 v1／v2／v3，原有工作模式、轴焦点、阈值、型号和步长保留；旧记录的检测结果默认为空。新格式继续使用现有 CRC、A/B 备份及异步写入。降级到只认识 v3 的旧固件不能读取新 v4 记录。

无需修改 CubeMX、接线或外设初始化。HAL、ST 官方库、KK_UI／KK_OLED 核心和中断分发源文件未修改；原有 HSO、六步、双机和通信功能保留。
