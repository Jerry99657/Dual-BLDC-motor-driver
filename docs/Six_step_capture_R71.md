# R71：统一预设与 ESC 的六步起转资格

本文保留 R71 的控制修改与验证记录。R72 沿用本页控制算法，设置入口改为 `Settings → System → Sensorless`，六步诊断独立为 `Status → Six Step`，详见 [R72 UI](UI_R72_sensorless_menu.md)。

2026-10-25，固件 **UI-R71-ESC**。用户确认：同一 2804，预设 Throttle 20% 报 NO ZC，ESC Auto 20% 可以运行。预设失败记录：

```text
ZC        2/12 P 52/105.1
Duty      9.1%
EMF       -0.34 V
Hold      500/500 ms
Start EMF 0.45 V
Cause     -
Sample    OFF
```

连续过零仅 2/12，说明失败发生于 SYNC，尚未进入 RUN。20% 是 RUN 的最终油门请求；对齐、正弦起转和 SYNC 使用启动电流及交接电压，不能把此时 Duty 9.1% 直接认作油门设置丢失。`EMF` 是最后一次浮相残差；`Start EMF` 是滤波后的启动 Uq 强度代理，两者不是同一物理量。

## 已确认的代码差异

R70 中，2804 预设与 ESC 的启动电流均为 0.25 A，SYNC 幅值约束均为 0.30 A，RUN 均为 0.50 A。相位窗、过零判断、退磁屏蔽、OFF／ON 采样与 TIM7 看门狗也共用。主要的启动差异是：

| 项目 | R70 2804 预设 | R70 ESC Auto |
| --- | --- | --- |
| Throttle 正弦起转目标 | 固定 20 电气 Hz | 随信号强度升频，最高 60 电气 Hz |
| 进入 SYNC 的强度资格 | `max(0.15 V, 0.01×VBUS)` | `max(0.6 V, 0.01×VBUS)` |
| 暂停升频 | 到达固定频率 | 至少 12 Hz 且强度达到 0.7 V |

因此，预设允许在较弱的启动信号下交接。0.45 V 符合旧预设门槛，却不符合 ESC 的 0.6 V 门槛，与用户的对照现象一致；这支持“交接条件不同”的方向，**并未通过实板波形证明它是全部故障的唯一原因**。

## R71 修改

2804、4015 和 ESC Auto 共用相同的六步启动信号资格：

- 按 20 电气 Hz/s 升频，最高 60 Hz；至少达到 12 Hz 且 Uq 强度代理达到 0.7 V 时暂停升频。
- 强度至少为 `max(0.6 V, 0.01×VBUS)`，电流跟踪合格，连续保持 500 ms 后允许交接。
- Speed 模式额外以请求机械速度对应的电气频率限制启动参考，不为获得更强信号而主动超出目标；若目标降低至当前启动参考以下，先降参考，期间清零交接保持计数。目标过低、强度不足时仍超时停止，不强行接管。
- 交接电压仍为 `√3 × (|Uq| + 0.2×|Ud|)`；随后仍须 12 次实际过零才能进入 RUN。

本轮没有增大电流、改变采样时刻或放宽过零判据。两套预设继续使用自己的启动电流、运行电流、额定电压限幅、机械 rad/s 与 Speed PI；ESC 保持油门／电气 Hz。原 FOC、HSO、双机、SPI2、W25Q64、配置格式及保护未作修改，无需调整 CubeMX。

`Start EMF` 仍包含电感压降，只是强度代理；真正的 RUN 资格仍来自悬空相反电势。较低的 Speed 目标不保证能从静止启动，不能用启动参考超速来掩盖这一边界。

## 验证与限制

新增真实六步控制器的定向测试：同一 2804 电气模型、12 V、20% 油门，分别以预设及 ESC 启动，比较进入 SYNC 时的电气频率、强度与保持时间；两者一致，均满足至少 0.6 V、500 ms。另测 15 rad/s 的弱信号场景：不超过请求的启动参考，不进入弱信号 SYNC，超时撤销输出。

独立电气／机械耦合模型补上此前缺少的 **2804 预设** 场景，使用与 ESC 相同的物理模型：Rs=2.3 Ω、Ls=0.86 mH、7 极对、磁链 3.2 mWb、惯量 5×10⁻⁶ kg·m²。这些是模型假设，未经本次实物辨识。

| 12 V、空载模型 | 末段实际机械速度 | 最大相电流 | 结果 |
| --- | ---: | ---: | --- |
| 2804 预设 Throttle 20% | 49.545 rad/s | 0.310 A | RUN |
| ESC Auto Throttle 20% | 49.545 rad/s | 0.310 A | RUN |
| 2804 预设 Throttle 30% | 72.582 rad/s | 0.310 A | RUN |
| 2804 预设 Speed ±30 rad/s | 约 ±30 rad/s | 0.310 A | RUN，无反转 |
| 2804 预设 Speed ±50 rad/s | 约 ±50 rad/s | 0.310 A | RUN，无反转 |

R70 的名义 2804 模型本身也能运行，**没有复现用户的确切 NO ZC**。本轮模型和单元测试用于核对两条路径已统一，并检查没有明显控制退化，不能据此宣称实板故障已消除。

`tests/motor_host/run.py` 和 `tests/ui_host/run.py` 全部通过，包含原有 4015 12／20 V、正反转、低速／降油门、FOC／HSO／双机、保护、编码器、Flash 保存、协议及按键回归。链接后启动／强中断检查、ELF/BIN 一致性和实际 Cortex-M4 Thumb 64 位除法 ABI 检查通过。未烧录实板。
