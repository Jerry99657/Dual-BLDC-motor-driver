# R116：合法零码、样本一致性与失联快照

日期：2026-10-30。固件 `UI-R116-ENC`。保留 R115 的位置／Follow 参数，本轮不继续整定低频运动。

协议参考：[MagnTek MT6701 Rev.1.8，第 25～26 页 SSI 时序与帧格式](https://www.magntek.com.cn/upload/pdf/202407/MT6701_Rev.1.8.pdf#page=25)。历史实板记录见 [2026-10-23 Follow 记录](Encoder_follow_field_log_2026-10-23.md)。

## 实板证据与结论边界

M2 为手转主机、M1 通电跟随。用户报告固定位置的小幅低频往复特别容易触发 ENC1 LOST。

| 首次故障 | 冻结的 F Enc | SPI2 Reset | 判断 |
| --- | --- | --- | --- |
| `2 M1 ENCODER1 LOST` | `E1 ALL 0 4/00` | 38 | 样本年龄超过原有 3 周期；结合零点前后原始码和回放，优先处理合法零码被拒绝 |
| `5 M2 ENCODER2 LOST` | `E2 ALL 0 0/00` | 仍为 38 | 仅此记录无法判定是哪项健康条件失败；不能等同于零帧超时或新的 SPI2 复位 |

历史 `SPI2 Fault=037D/1700/0882` 是最近一次总线恢复前的寄存器记录。`Clear diag` 不清除它或 SPI2 Reset。`Last ALL 0` 也会在后续成功帧之后保留，不能单独证明该帧导致本次停机。

## 修复行为

- SSI 角度、状态和 CRC 均为零是合法组合，CRC／FIELD／TRACK 检查仍执行。可信零帧像其他有效帧一样更新角度、时间戳、序号和年龄；不增加错误数或 ENC2 连续失败数。
- 全零帧发布前检查到零点的最短机械位移。限值为 `8 counts + max_speed_mech × 实际 DWT 采样间隔 × 16384/(2π)`，使用当前轴电机参数的最大机械速度，不使用运动目标。两个现有预设此上限均为 600 rad/s；8 counts 约 0.176°。
- `3→0→16382`、`1→0→0→16383` 等连续过零被接受；100 us 内 `1000→0` 超过限值时拒绝。仅全零帧使用新增检查，非零帧原来的校验策略保持。
- 尚无有效历史或 DWT 间隔超过 5 ms 时允许重新建立位置历史。长时间故障后不使用旧速度无限外推。这个准入不是电机输出重启；失联后仍需明确的手动启动。
- `Zero/ZPre/ZPost/ZTime` 继续记录全部零事件，包括正常零码；被接受的零码不再属于 `Frame/Err`。`Last ALL 0` 在本版表示最近一次全零帧因突跳被拒绝。
- CRC 和浮点换算在临界区外完成；角度／原始码／时标／年龄／序号和有效标志在一个短临界区发布。ENC2 快照的墙钟检查移到同一个临界区，防止不同状态混读。
- 编码器准入与故障冻结在同一短临界区完成，在电流变换和 PI 计算前恢复调用者的 PRIMASK。适应 CubeMX 改变中断相对优先级，不靠固定物理 IRQ 归属保证一致性。
- 检测专用的旧零码缺口桥接不再需要：`MT6701_HasNearZeroGap()` 保留兼容入口并返回 false，辨识使用正常有效零角度。

原有 3 周期样本年龄、5 ms 墙钟有效期、CRC、磁场／失跟踪、DMA 超时、未启用 ENC2 五次失败停止、需要 ENC2 时停机后的 250 ms 重试、SPI2/W25Q64 仲裁，以及 ADC／电流／IBUS／KEY1／控制超时保护均保留。没有增加自动输出重启。

## 新的冻结诊断

`Status → Diagnostics → F Enc Gate`，随 Axis M1／M2 选择物理轴。例：`E2 H10 T6 F0`。

- `H`：十六进制健康失败位，可以组合；`00` 表示快照时全部编码器健康条件通过。
- `T`：最后有效帧的墙钟年龄，单位 ms，超过 255 后显示 255。
- `F`：ENC2 连续失败计数，上限 5；ENC1 此字段为 0。

| H 位 | 含义 |
| --- | --- |
| 01 | 没有有效样本／M1 连续采样未启用 |
| 02 | 正在等待总线恢复 |
| 04 | ENC2 连续失败已达 5 次 |
| 08 | 实时采样年龄超过 3 个 ADC 周期 |
| 10 | 有效样本墙钟年龄超过 5 ms |

`E2 H10 T6 F0` 表示墙钟超时；`E1 H08 T0 F0` 表示周期年龄超限；H 是状态位，不是历史错误。原 F Enc、F Counts 等行保留，新行追加在诊断末尾，上位机和 USB／USART GetRow 使用同一数据。

冻结结构版本更新，旧 R115 保留 SRAM 记录不会按新结构解释。测试前停机执行 `Settings → System → Clear diag`，再启动 Follow；复现后保留 First、同轴 F Enc 和 F Enc Gate。通信恢复不会覆盖首次故障。

## CubeMX 与单链路限制

用户已在 CubeMX 设置 PA6/SPI1_MISO、PB14/SPI2_MISO 为 Pull-up 并重新生成。本轮只读取生成配置，未覆盖 GPIO、SPI、时钟或 DMA 初始化；SPI2 的原有设备协议切换保留。每次构建新增 MISO 上拉检查，按生成的路由查找引脚，不把 PA6/PB14 写死为运行时引脚。改变引脚后同样检查生成的 GPIO 配置。

上拉为开路输入提供确定的高电平倾向，使缺失编码器不再靠浮空读零碰运气。**真实静止零码与 DO/MISO 持续短接地仍可能产生完全相同的 SSI 数据，CRC 也无法唯一分辨。** 连续零不再直接判断线；不能宣称本版完整检测所有卡低故障。首次启动全零和长时间故障后的全零也存在这个单链路限制。硬件独立观测或额外的可靠链路证据才能进一步消除歧义。
