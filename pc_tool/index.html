运行曲线

每个画布只有一套 XY 轴，拖入的曲线直接叠加，共用时间 X 轴和数值 Y 轴，单位标在通道名中。通道可自由组合，也可放入多个画布；先选“当前画布”再勾选也能添加，点击 × 移除。

缓冲条红端改起点、紫端改终点、绿色中点／选区整体平移；预设窗口可直接输入秒数。拖拽、滚轮和框选期间持续更新，只有主动暂停才冻结；最新点默认为 0，跟随最新恢复右端对齐，各画布独立。

Settings 编辑

选中电机

全局

导入会预览改动，确认后锁存暂停并逐项应用；发生拒绝即中止，已生效的项可重新读取确认。不会自动启动电机。

电机参数辨识

使用板端现有 Single M1 编码器辨识，电机会转动。保存结果不自动替换型号预设；进度与结果见实时板端状态。

板端诊断详情

复用板端 Status 行；逐行采样，带板端时间，不改变 LCD 当前 View。R95 的 Diagnostics 附加完整中断时序、首次故障和 CPU 异常记录；仅停机后可清除，清除不会解锁保护。
