# UI-R36-SMOOTH：慢速输入整形与停止捕获

此页保留 R36 历史实现。用户板上报告振动更强及停止振荡后，R37 已撤回慢速额外 P、原始位置旁路和末端 PD，改为带滞回的近静止保持，见 [4015_follow_stability.md](4015_follow_stability.md)。当前 **UI-R38-SMOOTH** 继续改善移动输入整形，见 [4015_moving_smoothness.md](4015_moving_smoothness.md)。

适用当前设置：4015 从轴、Curr Loop=On、空载。用户确认的现象是持续转动但快慢起伏，手动加初速后自由滑行则较顺；高速目标仍为 ±10°、4 Hz。补充观测为主机停下时 Run Error≥3 rad，从机约晚停 0.5 s，时间读数尚不准确。本版支持两轴交换主从，无需修改 CubeMX 或设置保存格式。

## 判断与资料

自由滑行时更顺，提示手动转动的速度变化可能参与了输入波动；这不能单独证明顿挫全部来自手。14 位 MT6701 的角度台阶、速度前馈、闭环响应、摩擦及齿槽扰动都可能叠加。需对照主从实际角度/速度及电流曲线区分。

[Synapticon 的速度前馈说明](https://doc.synapticon.com/node/sw5.0/motion_control/advanced_control_options/feedforward.html)指出，对位置求导会放大量化和输入噪声，强滤波又增加延迟。[其反馈滤波说明](https://doc.synapticon.com/actilink_s/sw5.6/motion_control/advanced_control_options/filtering/low_pass_filter.html)也提醒滤波会改变相位。因此本版将输入整形与从机反馈分开，保留从机的 R35 速度估计带宽。

输入整形借鉴 [Casiez、Roussel、Vogel 的 1€ Filter](https://gery.casiez.net/1euro/)：慢速降低截止频率抑制抖动，快速提高截止频率减少滞后。这里自行实现分段连续的速度调度、双通道融合与末端处理，没有直接引入作者代码；参数是本工程模型验证后的实验预设，不是论文推荐的电机参数。

## 已实现

1. 两轴保留 R35 alpha-beta 估计，alpha=0.5、beta=0.08、周期 1 ms。从机电流/速度反馈直接使用原带宽，避免为平滑主机输入而降低反馈相位裕度。
2. 另建立主机命令通道：原始角度差分先经约 10 Hz 低通，再按速度调整位置低通截止频率。使用后向欧拉系数 `alpha=2*pi*fc*Ts/(1+2*pi*fc*Ts)`；截止频率为 `clamp(2+10*abs(v)+50*max(0,abs(v)-0.3),2,100)` Hz，v 为滤波后的机械速度 rad/s。正常运动时，从滤波位置的增量产生一致的速度前馈。
3. 主机的速度活动度以约 50 ms 时间尺度平滑；活动度 0.3～0.7 之间连续融合慢速整形与 R35 快速通道。持续高速/快速往复优先使用原快速通道，减小慢速平滑对 4 Hz 响应的影响。
4. 跟随误差较小时，位置修正对照真实主机目标，速度前馈走平滑通道；误差增大时平滑返回受约束的追赶参考。Run 的 Error 始终是原始主从目标误差，不用滤波后的小误差掩盖落后。
5. 慢速且仍在运动时，速度 PI 的比例底值平滑提高，最高从 0.05 增至 0.08；大速度误差仍最多 0.10 A/(rad/s)。接近静止时回到原底值，积分增益仍是 0.5，保留饱和条件积分。增加积分的试算在部分停止模型中不满足原有界限，未采用。
6. 按编码器计数间隔判断输入安静：至少超过 4 ms，且超过此前计数间隔的两倍。间隔会随慢速计数变化；长时间静止后的新计数重新开始估计。它是量化观测下的安静判断，不是 MCU 停止读取编码器，也不直接停止功率输出。
7. 输入安静后，命令位置滤波提高截止频率以消除尾部，速度前馈连续衰减，避免滤波位置追上原角度时产生速度尖峰。真实主从角差小于 0.1 rad 时，以约 10 ms 时间尺度融合到末端位置保持：`速度目标=-6*原始跟随误差-0.5*从轴估计速度`。此式在速度外环前提供位置修正和速度阻尼，仍由原速度 PI、电流环、斜坡和限幅执行，不是直接给转矩。

每次 Follow 都重新初始化所有观察器、滤波、计数间隔及捕获权重。仍按确认的实际从轴/电流模式绑定预设，设置草稿不改变正在运行的执行器。Stop、KEY2、编码器失联和故障停机流程保留。

## 停得晚需要区分

- 若主机已静止但速度估计/参考仍残留，输入安静处理和末端捕获用于减少这部分拖尾。
- 若 Run 的 Error 仍明显，从轴还需要追赶真实角度，实际电流、惯量和带宽决定需要多久。
- 只把从机速度强制清零会留下角差。本版继续保持位置闭环，不能保证任意初速下与主机同时停转。

用户补充的 Error≥3 rad 相当于约 172°；假设读数对应停下那一刻，它表明存在很大的真实落后，晚停不能仅归因于滤波拖尾。要保留机械角度一致性，就需要继续补足角差。若 3 rad 在 0.5 s 内补足，平均追赶速度约为 6 rad/s，仍需考虑加减速过程；将速度强制归零会破坏原目标。

小角差滑行模型中，R35 的速度停止延迟约 7～9 ms，本版约 10～15 ms；同时本版的终点角差更小。大角差拨转模型见下文，追赶到角度范围与最终速度静止并不等价。停止的定义、角度误差和速度阈值必须同时报告，不能把“更接近目标角度”误称为“更早停转”，也不能声称实机晚停已经解决。

## 模型比较

使用真实两轴协调器/外环、14 位角度量化、250 rad/s 理想一阶电流执行器，电流到加速度增益取 300/1500/3000 rad/s²/A；包含静/动摩擦、齿槽扰动。这些都尚未实物辨识，不能替代电压饱和、真实 RL/PWM、回馈、通信时延和温升验证。

下表为 M1 从轴；M2 同样通过对应界限。统计舍弃最初 1 s。

| 模型工况/指标 | R35 | R36 |
| --- | --- | --- |
| 0.2 rad/s 匀速，实际速度起伏 RMS | 0.078～0.089 rad/s | 0.072～0.080 rad/s |
| 0.2±0.08 rad/s、6 Hz 输入，实际速度起伏 RMS | 0.095～0.106 rad/s | 0.087～0.090 rad/s |
| 同输入，输出 6 Hz 速度波动幅值 | 0.054～0.101 rad/s | 0.052～0.075 rad/s |
| 0.2 rad/s 加一计数、37 Hz 主机角度噪声，速度误差 RMS | 0.081～0.092 rad/s | 0.073～0.080 rad/s |
| 同角度噪声，Iq 指令变化率 RMS | 1.51～1.79 A/s | 1.30～1.39 A/s |
| ±10°、4 Hz，角误差 RMS | 1.02～4.54° | 约 0.98～4.49° |

慢速起伏没有消失。0.03 rad/s 极低速模型仍受设定的静摩擦和齿槽扰动影响，部分执行器的速度 RMS 不比 R35 小；保留此结果，不能宣称解决所有低速工况。未加入未经辨识的摩擦电流或 J/Kt 前馈。

停止模型为：先给 4 rad/s，再以 2 rad/s² 减速，在接近零速时结束主机运动。以主机停下后从轴最后一次超过 0.02 rad/s 的时间定义速度停止延迟，单独报告终点角差。R35 的终点角差约 0.00395～0.01528 rad，本版约 -0.00048～0.00923 rad；不能把这个角差改善当作速度停止时间改善。

另增大角差拨转：主机初速 40 rad/s，0.3 s 内线性降为零，总共转约 6 rad。主机停止时模型从轴落后约 3.44～3.67 rad，与用户反馈处于同一量级；R36 在随后约 0.235～0.758 s 内进入并保持在 0.1 rad 角差范围，R35 为约 0.237～0.748 s，不能据此宣称大角差追赶提速。模型中仍可有摩擦引起的后续小幅补角；以最后超过 0.02 rad/s 定义的完全速度静止约需 1.10～4.28 s，部分执行器比 R35 慢。这些未辨识模型没有证明实机也会出现相同拖尾，但明确提示不能把“完成大部分追赶”当成“立即静止”。测试分别记录停止时角差、进入角度范围的时间及两个速度阈值，保留这项限制。

大角差继续沿用原有受约束追赶预设。提高其加减速度的试算虽减小了拨转落后，却使低加速度执行器的原有反向超调/停止界限失败，未合入。继续优化这部分需要实测角度、速度和 Iq，并核对实际电流环响应与惯量。

新增 0.2 rad/s 匀速/变速、主机角度噪声、0.03 rad/s 稀疏计数、滑行停止及大角差拨转；既有 4 Hz 往复后停止、大角度/反向、换向、偏置、限速、两轴互换、饱和积分和重启检查继续通过。所有模型的 Iq 仍限制在 ±1.2 A。

## 上板与定位

烧录本次 Debug 或 Release，About → FW 应为 **UI-R36-SMOOTH**，继续使用从轴 4015、Curr Loop=On、Pos Speed=120、Speed Limit=120。先比较同样慢转动作，再逐步恢复 ±10°、4 Hz 往复。

观察停止时的 Run Error：它仍是最终机械角差。JustFloat 的 M1/M2 位置分别为第 14/20 通道，速度为第 2/18 通道，M2 实际 Iq 为第 21 通道，最终跟随误差为第 25 通道。显示的普通速度仍使用原来的诊断测速，不是内部所有滤波状态。

若主机角度/速度曲线本身明显起伏，自由滑行更顺就支持输入差异的解释；若主机较匀而从机明显起伏，继续检查从机实际 Iq、速度环、编码器误差与摩擦/齿槽。齿槽补偿或摩擦模型需要实测辨识，不能靠任意加补偿电流处理。

## 验证与资源

电机/采样/编码器/HSO/协议、UI/存储/LCD、USB CDC 主机回归通过；Debug、Release 构建与最终 ELF/BIN 启动顺序、一致性检查通过。新增滤波在 1 kHz 外环执行，实际双电机中断耗时仍需上板确认；既有超时保护保留。尚未烧录或做硬件闭环验证。

Debug：Flash **131020 / 131072 B**，余 **52 B**；RAM **21608 B**。Release：Flash **130244 B**，余 **828 B**；RAM **21512 B**。增加 UART/UARTEx 与已有 SPI/GPIO/USB 代码的 LTO 共享，并使用单一 LTO 分区；HSO 初始化/配置入口按大小优化，10 kHz HSO 算法仍按原优化配置编译。所有功能保留，Flash 余量很小；后续增功能需重新核对体积。
