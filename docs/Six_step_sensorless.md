# M1 六步无感：UI-R71-ESC

2026-10-24。本版在编码器 FOC、独立 HSO FOC 之外，提供单 M1 的六步无感油门及速度控制。原有双有感独立／同步／主从、两套电机预设、按键、W25Q64、USB、连续 ADC/VREFINT 和保护保留。六步不依赖编码器或 ST HSO 静态库，不提供位置控制；RUN 无 dq 电流控制，起转辅助使用相电流闭环。实际相电流及全部过流保护持续工作。

## R71：预设与 ESC 共用启动资格

用户确认 2804 预设／ESC 同为 Throttle 20%，预设以 Start EMF 0.45 V、2/12 过零报 NO ZC，而 ESC 能运行。R71 将两套预设的六步启动也改为 ESC 的升频／信号强度资格，取消固定 20 Hz 和较低的 0.15 V 交接门槛；Speed 启动参考仍不主动超过目标。原电流限幅、12 次实际过零、采样及保护保留。现象、证据边界、20% 对照及复测见 [R71 启动资格](Six_step_capture_R71.md)。无需修改 CubeMX。

## R70：ESC Auto 通用油门（历史）

2026-10-25。停止并满足静止资格后，选择 `Single M1 → Six Step ON → Settings → Motor → ESC Auto`。Run 仅使用 0～100% 油门，显示电气 Hz，不填写极对数／Rs／Ls／KV／磁链；明确选择 2804／4015 即返回原预设及机械 Speed 控制。选择可掉电保存，不自动启动。共用六步起转改为固定电流 PI、滤波稳定资格及实测电压交接，预设模式的六步启动也受此变化影响。

通用模式使用保守的 0.25 A 启动电流、0.5 A RUN 幅值约束和 2 A 瞬时软件过流；硬件 IBUS、原 ADC／全局停止等保护保留。无需更改 CubeMX 或 SPI 配置。操作、实现、两台电机的独立模型对照、固件哈希和实板复测边界见 **[R70 通用六步说明](Six_step_ESC_R70.md)**。

下文保留 R60～R69 的历史设计与排障记录；其中旧起转 PI、Rs／Ls 估算及遥测单位已由上述 R70 说明替代，不能作为 ESC Auto 的当前操作依据。

## R69：启动时的 Flash 识别重试

R69 在启动、尚未运行电机时补上 W25Q64 的三次有限 ID 尝试和初始化错误保留；没有调整 SPI2 模式／速率／片选或六步控制。切换 2804 后 Save NO FLASH、复位恢复的实板反馈、证据边界及验证见 [R69 Flash 初始化](Flash_init_retry_R69.md)。R68 的型号切换修复继续保留。

## R68：修复无感模式的型号切换

2026-10-25，用户在 Single M1 六步下将 4015 切为 2804，始终提示 `Stop/check encoder`。实际控制后端已经使用相电流／相电压的连续 200 ms 静止资格，且绕过编码器准入；问题是 Motor 菜单在检查前无条件调用 Stop，清零六步静止计数，紧接着的型号切换因此必然失败。

R68 在已停止的六步／HSO 模式下保留该静止资格；若输出仍运行，先停止并等待重新具备资格后再确认。不改变静止检查、运行拒绝、保护或六步采样算法。无感模式失败提示为 `Wait for stop`，成功为 `Motor set`；编码器模式继续使用原检查和对齐提示。更换型号仍清空运行目标、沿用原保存流程，不自动启动。Settings → Motor 选择 2804 后可按原 Single M1／Six Step／Throttle 流程试转，无需修改 CubeMX。

新增回归先在真实控制器中复现“空闲 Stop→立即切换拒绝”，再核对编码器失联且残留 300 rad/s 旧读数时，电气静止满 200 ms 后两套型号可切换、运行及等待期不能切换；真实 UI 菜单回归覆盖六步／HSO 的双向确认、无冗余空闲 Stop、目标清零和不自动运行。Debug／Release 及原电机／UI／存储／LCD 回归通过，尚未实板验证 R68。

用户在 R67 已确认 20% 油门可以运行；15% 油门缓降后运行 1～2 s 出现 PHASE，在相近速度下使用 Speed 也出现 PHASE。最近诊断为 `0/12 T 65/146.1`、Duty 12.8%、Cause PERIOD HIGH、Sample OFF。该现象更支持当前配置接近低速稳定边界；尚无波形证实真实转子减速与检测误差各自贡献，不应视为电机的物理最低速度。R68 保留原门限。

## R67：自适应采样与时序诊断

低实际占空比使用峰顶 OFF 采样，高占空比使用谷底 ON 采样；新增 `6S Cause`／`6S Sample`，周期比显示一位小数，并保留最近六次候选周期。门限、启动流程和保护保留。实板 R66 的 `0/12 T 65/145` 反馈、ST 官方依据、改动、模型对照和复测步骤见 [R67 采样说明](Six_step_R67_sampling.md)。后续实板低速反馈见上文 R68。

## R66 历史：先验证起转，再接管六步

用户连续遇到 NO ZC、PHASE、RAMP START TIME，且起转明显卡顿。前几版主要用预设转子轨迹验证过零判据，假定转子能跟上强拖，**不能证明真实启动可靠**。本版重新对照源程序和启动模型，不继续扩大相位、周期或超时门限。

### 确认的代码问题和证据边界

1. 旧强拖从 **1.5 电气 Hz** 起步，每 60° 驻留约 **111 ms**。对低 KV 云台电机，这种离散磁场在低速会拉动、停住、再拉动；旧启动没有连续旋转电流矢量。
2. 旧代码在约 3 电气 Hz、连续 6 次候选过零后就让 BEMF 接管，12 次即开启速度环。转子摆动的速度换向也会使反电势经过零；符号、相位窗口和计数本身不能充分证明单向稳定旋转。
3. 旧独立波形测试预设转子跟随强拖速度，无法发现前两项。新增电流→转矩→机械运动模型后，旧 R65 在 12 V／30 rad/s 命令下仍可显示 RUN／12 次资格，末段平均实际速度却约 **2 rad/s**，伴随往返摆动，最大相电流约 **1.64 A**。这是模型反例，不能断言实板全部故障都由它造成。
4. 现有三相电压网络的 40 μs RC、错时 ADC、器件误差仍是独立风险。增加 36／44／40 μs 的 RC 失配后，新模型也可出现 SYNC 后 NO ZC；测试要求如实停机，**没有将该场景算作运行成功**。本版尚未进行 RC 在线辨识或实板波形校准。

4015／30 rad/s 对应约 52.5 电气 Hz，每 60° 约 3.17 ms，可得到约 32 次 10 kHz ADC 采样，不能仅凭本次转速就认定 ADC 频率不足。40 μs RC 对基波的单纯延迟也不足以独自解释全部现象；PWM 共模、通道误差及启动失步需分别核对。现有 ON 采样在实际占空比低于约 9.4% 时仍不可用。

### 当前流程

- **ALIGN**：三相互补 PWM、固定电流角，Id 以 400 ms 斜坡到额定电流的 50%，Iq=0。4015 为约 0.60 A。对齐阶段 PI 电压限制在与 Rs／电流对应的低压范围；1 s 后电流跟踪不满足条件则 `6STEP CURRENT` 停机。
- **SINE**：不使用编码器的 I/F 起转；10 kHz 连续推进电流角，以 **20 电气 Hz/s** 加速到 `min(20 Hz, Speed 对应电频率)`，油门模式起转目标为 20 Hz。只使用相电流和已有电压调制器，不调用 HSO 观测器。
- **稳定检查**：达到起转频率、Id/Iq 误差各小于目标电流的 20%、估算反电势强度大于 `max(0.15 V, 0.01×VBUS)`，连续维持 **500 ms**。估算采用低通后的 `|Uq−ωe×Ls×Id_ref|`，先扣除强制旋转电流自身的感性电压。此量是强度检查，不是无误差的转子角测量。
- **SYNC**：在正确电流角边界切至六步扇区；以估算反电势和较小电阻压降初始化输出，避免带着原 50% 附近的正弦 PWM 宽度接管。切换时断开输出、立即装载相等 CCR、恢复预装载，再接通对应桥臂，不重置共享定时器／ADC 时基。此后由实际过零安排约 30° 延迟换相，保持原时序校验和丢过零看门狗。
- **RUN**：连续 12 次实际六步过零通过后，预置速度 PI 或进入油门控制。RUN 仍为两相导通、一相悬空的反电势六步，无 dq 电流调节；SINE 阶段的电流环属于固定启动辅助，不受 Settings 中编码器电流环偏好控制。

整段启动仍最多 8 s；故障、KEY1、KEY2／Stop、Speed 0 和 Throttle 0 的停止路径保留，不自动重启。相电流、过载和 COMP4→TIM1 Break 硬件保护持续有效。无需修改 CubeMX。

### 诊断与验证

About 版本为 **UI-R66-6STEP**。正常阶段应为 `ALIGN → SINE → SYNC → RUN`，起转时的 Est 尚不是实测转速。

Status → Drive 增加：

| 显示 | 读法 |
| --- | --- |
| `6S Hold` | 稳定检查已连续维持的毫秒数／500；失败会重新从零计数，故障后保留。 |
| `6S Start EMF` | I/F 阶段估算的反电势强度，单位 V；与原 `6Step EMF` 浮空相瞬时残差不同。 |
| `6S ZC` 末尾代码 C／E／S | SINE 的电流未跟踪／估算 EMF 不足／继续升频或稳定等待。SINE 不累计六步资格，不能将其 0/12 理解为过零检测失败。 |

进入 SYNC 后，原 W／P／Z／K／T、过零相位和周期百分比继续使用。NO ZC 后的 `12/12 Z 51/102` 只说明此前最后一次过零通过、之后未等到新的有效过零；它不是“资格已经满了所以不该停”。瞬时 EMF 接近零也不能直接当成反电势峰值。

SINE 阶段的 Duty 为等效线电压幅度／VBUS，三相实际 PWM 宽度各不相同；SYNC／RUN 后才是六步高端 PWM 的占空比。

新增 `test_sixstep_plant.c`：三相星形等效 Rs/Ls、正弦磁链、PWM 桥臂、浮空相二极管续流、40 μs RC、ADC 量化／实际 Rank 时刻插值，以及机械方程 `J×dω/dt=电磁转矩−黏性摩擦`。转子位置和速度从未赋值成控制器的目标、参考或扇区。假定 ψ=7.5 mWb，J 分别为 1／2／4×10⁻⁵ kg·m²，黏性摩擦 3×10⁻⁵ N·m·s/rad；**未辨识实物惯量、磁链、死区、电压增益、齿槽和 Delta 循环电流**。

12／20 V × 正反转 × 三组惯量，12 组名义模型均完成起转及 9 s 运行，末 0.5 s 实际／估计均速接近 ±30 rad/s；相电流峰值约 0.67～0.70 A。堵转模型停在 START TIME，电流反馈全零模型在 1 s 停为 CURRENT，KEY1 在 SINE 阶段停止；RC 失配模型保留故障停机。原电气迹线、真实采样驱动、FOC／HSO／双机／存储／LCD／输入／USB 回归继续执行。这些结果不能代替实板重复启动和持续运行验证。

为容纳启动代码，新增 `MotorMath_SinCos` 共享芯片已有 CORDIC，释放 CMSIS 的 2052 B 正弦表及对应函数。每次事务设置余弦功能、精度、32 位格式和单位模长，并完整读取两个结果、恢复原 PRIMASK；不沿用 HSO 上次的 CORDIC 状态。专用主机寄存器模拟覆盖 20001 个角度、π 边界相邻浮点数、既有 HSO 状态及关中断调用；它核对接口和格式，未模拟真实硬件运算误差。HSO 控制流程／参数及 O2 设置保留，三角函数由 CORDIC 计算。

R66 交付时尚未实板验证；后续用户确认 About 为 R66，反馈的低速及降油门故障见 [R67 说明](Six_step_R67_sampling.md)。需要采集浮空相、另两相及 PWM 的同步波形来确认 RC／采样／续流问题，不能继续凭几项停机数值认定全部根因或扩大门限。

## R65 历史：修正 87/137 对应的相位归一化

实板继续反馈：`PHASE`、`0/12 T 87/137`、Duty 39.6%、EMF 0.04 V。沿用前次 4015／12 V／空载／Speed 30 rad/s 条件分析。这一次明确是旧相位检查拒绝；周期比 137% 本身仍在 55%～145% 范围内。

R64 使用上一个周期 P 同时计算 `phase=(候选过零−换相)/P` 和 `ratio=本次过零间隔/P`。前一次换相安排在上一个有效过零后约 0.5P，因此当本次间隔为 1.37P 时，候选自然位于换相后 `1.37P−0.5P=0.87P`。周期门限接受 137%，相位门限却拒绝 87%：原判据额外限制了本来允许的减速变化。

R65 在 **SYNC／RUN** 中用本次测得间隔归一化候选位置：同一事件由 87% 改为 `87/137≈63.5%`。RAMP 仍按强制换相周期校验。相位窗数值 10%～85%、相邻周期范围 55%～145% 均保留；本次更改的是闭环相位百分比的时间基准，不能直接把新版位置数值与旧版比较。这个百分比是时间比例，不是编码器测得的电角度。

新增独立、连续的正反转减速波形：先稳定六次过零，再按解析转子角度／速度轨迹，使下一次 60° 间隔约为此前的 137%，随后维持新的速度。原 R64 在该波形上复现 **PHASE 87/137**，R65 读到约 **63/137**，继续通过至少六次过零并持续运行。模型保留 PWM、40 μs RC、错时 ADC、量化及钳位；没有使用控制器扇区奇偶或其判据来生成转子角度。它验证了判据的一致性，尚不能证明实板转速变化的根因或后续运行稳定性。

原来在 RUN 后把过零延到旧周期 95% 的测试，也会对应约 145% 的相邻间隔，不能再一概当作非法相位。异常测试改为延到 110%，使相邻间隔超过 145%，仍须 PHASE 停机、取消定时器并保留诊断。冻结／反向转子、丢过零、启动超时及 KEY1／IBUS 等回归继续通过。

`6S ZC` 的格式不变；SYNC／RUN 后面的第一个百分比现按本次测得周期解释，第二个仍为本次／上次间隔。EMF 是候选确认附近的瞬时残差，0.04 V 不能单独当作反电势峰值或信号强度。若实板仍失败，记录新版本、完整 `6S ZC`、6Step Speed、Duty、EMF 及阶段。

本轮无需修改 CubeMX，未改变启动功率、速度 PI、输出模式或电流保护。**R65 尚未烧录／实板验证**。30° 定时的流程参考仍为 [ST 六步算法](https://wiki.st.com/stm32mcu/wiki/STM32MotorControl%3A6-step_Firmware_Algorithm)；这里的相位／周期判据及其归一化修正属于本工程实现。

## R64 历史：RUN 后失步检查与换相定时修正

实板反馈：4015、12 V、空载、Speed 30 rad/s，已经显示过 RUN，之后 `6STEP PHASE`、Qual 0/12 T、Duty 39.8%、EMF 0.07 V。Qual 在时序拒绝时清零；这组数据表示接管后某次候选过零的相位或周期越界，不能仅凭瞬时 EMF／占空比确定实际失步还是干扰。

代码确认存在定时滞后的路径：原来先按 25% 新值对过零周期滤波，再用这个滤波周期计算下一次约 30° 换相延迟。低速快速加速时，旧的较长周期仍占较大权重，换相会偏晚。R64 改为：

- 换相定时、下一步相位／周期校验和看门狗使用最新一个**通过校验**的过零周期；速度估计单独按 50% 新值滤波，不再让速度平滑拖慢换相定时。
- Speed 每毫秒参考增量限制为 `min(0.04, 0.00005×估计机械速度²×极对数)` rad/s，减速增量上限为其两倍。低速下减少稀疏反馈间的目标增长，随着转速升高恢复原 40 rad/s² 的加速上限。Speed 0／Throttle 0 仍直接滑行关输出。
- 过零相位窗口仍为 10%～85%，相邻周期比仍为 55%～145%，原两帧滞回、丢过零停机、启动超时、KEY1、IBUS、相电流和过载保护保持。没有通过忽略 PHASE 或自动重启来继续输出。

Status → Drive 原 `6Step Qual` 行改名为较短的 **`6S ZC`**，为同一行的诊断留出空间。例如 `0/12 T 92/148`：

| 项目 | 含义 |
| --- | --- |
| `0/12 T` | 连续资格数／12，以及原检测代码；T 为时序拒绝 |
| `92` | 最近一个两帧滞回确认后的候选过零，位于换相后该步周期的 92%；正常窗口 10～85 |
| `148` | 该候选与前一个有效过零的间隔，是上一周期的 148%；正常窗口 55～145 |

数值是整数百分比，上限显示 999；开始尚未得到候选时为 0/0。故障停机后保留候选数值，新启动时清零。P／Z／W 是当前检测进度，后面的百分比则保留最近候选，不代表每一帧都有新过零。**若本版仍失败，优先记录完整 `6S ZC`、6Step Speed、Duty、EMF 和阶段。**

补充的电气采样模型持续运行到 RUN 后 2 s：12／20 V、正反转、预设 5→40 rad/s² 的连续转子加速，以及端电压噪声；另有 12 V 正转接管后立即 40 rad/s² 加速。原 R63 在后一场景丢过零，新定时路径通过。该模型独立生成转子角度、相端 PWM、40 μs RC、错时 ADC、量化和轨端钳位；它没有辨识实际惯量／摩擦／电流转矩关系。复现的是加速丢过零，不能认定为实板 PHASE 的唯一原因。

减速到 10 rad/s 的模型也覆盖已知 ON 采样窗口边界：20 V 降功率时可能低于约 9.4% 占空比而失去窗口，此时要求 W／NO ZC、安全关断，不伪造持续闭环成功。另行注入 95% 步周期才过零的畸形波形，仍须立即 PHASE 停机，并保留越界的百分比。原 FOC／HSO／双有感、油门、存储、USB、LCD 和按键回归继续执行。

本版无需修改 CubeMX。复测仍先用 4015／12 V／空载／Speed 30 rad/s；R64 尚未烧录或实板验证。仅整理重复的 UI 模式判断及六步速度边界计算以容纳诊断，未删减功能或更改其他控制参数。

## R63 历史：修复 SYNC 接管，增加油门模式

实板已能进入 SYNC，Qual 12/12 Z、Duty 22%、EMF 0.27 V，但尚未进入 RUN。代码中发现：SYNC 仍使用启动电压／电流约束，同时要求转速达到约 12 Hz 才开启速度 PI，可能无法自行达到该门槛。现改为连续 12 次过零通过极性、相位及周期校验后进入 RUN，不再附加 12 Hz 接管条件。Speed 的命令范围仍为 12～200 电气 Hz；资格本身和看门狗没有取消。独立电气迹线增加固定低转速 SYNC 场景，验证低于旧门槛也能完成接管，不能据此保证实板已修好。

按用户选择增加两种 Run 模式，左右短按在两者间切换，切换先停止，再按 OK 启动：

| 模式 | 输入与作用 | 操作 |
| --- | --- | --- |
| Throttle | 0～100%，直接请求输出幅度，无速度 PI；反电势仍负责换相 | 上下每次 1%，支持长按；0% 滑行停止 |
| Speed | 正负机械角速度 rad/s，保留速度 PI | 原 Speed 步长及 Speed Limit；0 滑行停止，反转先停机 |

Run 标出 `M1 Throttle 6STEP`／`M1 Speed 6STEP`、百分比／rad/s、VBUS、Est 和实际阶段。Status 的油门目标也标 `%`，不是 Uq 或 Iq。六步中不提供 Torque／Position 控制；内部沿用 Torque 枚举槽承载油门，但串口 `Torque:` 在六步下明确拒绝，避免把 V/A 误作百分比。

油门启动也先经过 ALIGN → RAMP → SYNC，使用原有固定、限流的启动辅助；不会因为输入 100% 而直接全压起转。RUN 后的请求电压为 `min(0.85×VBUS, 电机预设额定电压) × 油门/100`，实际占空比另受输出斜坡及电流约束。因此 **100% 油门不等于桥臂 100% 占空比**，仍为自举留出关断时间。0% 立即关输出，不等待斜坡。油门方向固定正向；需要反转时先停止再使用负 Speed。Speed Limit 约束 Speed 命令，油门没有速度调节器；检测到过零间隔短于 833.3 μs（200 电气 Hz）时以 `6STEP FAST` 停止，保护当前采样带宽。

低油门不保证可维持转动：当前只在 PWM ON 有效窗口检测，约低于 9.4% 实际占空比时采样窗不足，可能 `6STEP NO ZC` 停机；不能无限盲换相维持输出。建议仍用 4015／12 V／空载，先复测原 `Speed:30` 的 SYNC 接管，再试 `Throttle:20`。这是一套使用现有 ADC/RC 的控制实现，尚未验证所有电机／电压／油门组合。

串口例子：配置 `Work:SingleM1`、`Feedback:SixStep`，等待主循环执行完成后发送 `Throttle:20`；运行中可继续发送 `Throttle:25`。`Throttle:0`、`Speed:0`、`Stop`、KEY1 均能停止。Speed 与 Throttle 运行中禁止直接互换；先 Stop，并等电气静止确认完成后再启动另一模式。输入只在当前 Single M1 六步模式下接受；`M2:Throttle:20`、FOC／HSO 下的 Throttle、非数／超范围输入被拒绝。

已确认的油门单独存入 v3 `control_config[22:16]`，旧记录为零；长度、CRC 和 A/B 布局不变，不覆盖 FOC 的 Uq/Iq 或 Speed 目标。UI 保存后重启／重进页面可恢复数值，输出仍为停止。更换 M1 型号和恢复默认时清零油门目标。

参考 [AM32 官方主程序](https://github.com/am32-firmware/AM32/blob/main/Src/main.c) 中油门映射、输出斜坡与过零定时分离的控制方式，自行扩展本项目代码，没有复制其代码或接入 DShot。当前 10 kHz ADC、两帧确认与 40 μs RC **不具备穿越机高速电调的完整带宽**：7 极对、30000 rpm 时每步约 47.6 μs，比 100 μs ADC 周期还短。若要该转速等级，后续需重新设计过零捕获／采样和相电压滤波；COMP4 继续专用于 IBUS 保护。本轮不需要修改 CubeMX。

为容纳新增功能，合并 UI 中重复的型号切换复位逻辑、共享数值格式化／模式判断，并让 COMP/DAC/Cortex HAL 参与现有 LTO；COMP/DAC 的真实 MSP 钩子在 USER CODE 区显式保留，链接检查继续要求强符号。没有删除现有功能、字库字符或保护，也没有修改 HSO 快速计算的 O2 设置。

## R62 历史：对齐后的起转扇区与换相同步

继续收到实板反馈：4015、12 V、30 rad/s，ALIGN 可以保持，RAMP 持续单向转动，但 Qual 0/12，Duty 22.4%，EMF −2.05 V，Est 原显示为 Act 2.5 rad/s。这说明有开环输出，却未进入有效的反电势闭环；未锁定时的单个速度／EMF 值不能证明同步正常。

核对 [ST AN4220 第 10 页](https://www.st.com/resource/en/application_note/an4220-sensorless-sixstep-bldc-commutation-stmicroelectronics.pdf) 后修正对齐衔接：U+V− 对齐后的转子磁链位于 −30° 电角度，正向起转立即使用 V+W−，反向使用 W+U−，即向对应方向推进两个扇区（120°），随后每次再走一个扇区。旧代码先继续保持对齐扇区，再按普通一步换相，缺少这一初始转矩相位。

启动现在分为 `ALIGN → RAMP → SYNC → RUN`：

- RAMP 保留强制换相和启动电压斜坡。至少连续 **6 次**过零通过原极性、相位与周期校验，且强制电频率达到 **3 Hz**，才进入 SYNC。
- SYNC 的换相由过零后约 30° 延迟决定，速度环仍未闭合，启动电压／电流约束保持。R62 原来要求连续 **12 次**有效过零且观测电频率约 **12 Hz**；R63 删除后者，按当前输出预置速度 PI 或进入油门输出控制。
- SYNC 和 RUN 都有 TIM7 丢过零看门狗，未收到下一次过零时停机，不能继续按旧周期盲换相。原 8 s 启动期限和 KEY1／IBUS／相电流／过载保护继续生效。

Run 速度使用 `Est` 标识估计值。R62 的 Status → Drive `6Step Qual` 增加末尾检测代码，例如 `0/12 P`（R64 改名 `6S ZC` 并附带百分比）：

| 代码 | 含义 |
| --- | --- |
| A | 正在对齐 |
| W | ADC/PWM 有效采样窗口不满足 |
| P | 尚未见到预期过零之前的反向极性 |
| Z | 已见反向极性，等待过零及正向滞回确认 |
| T | 检测到变化，但过零相位或相邻周期不符合要求 |
| K | 最近的过零已通过校验 |

它们描述当前检测门槛，不是对 PCB 或电机的硬件故障判定。持续单向转动仍未接管时，请提供版本、最后的 RAMP/SYNC 状态、带字母的 Qual、Duty、EMF。故障后 Duty 保留最后命令；输出已经关闭。

新增独立三相正弦磁链 → 相端 PWM → 40 μs RC → 错时 ADC 与量化／钳位的电压迹线测试，角度不由检测器的奇偶／正负判据生成。12 V／20 V、正反转可通过同步与速度环接管；冻结和逆向转子迹线不能接管。单独恢复旧对齐衔接时，该测试复现 START TIME、Qual 0、过零累计 0；新衔接通过。同样覆盖 SYNC 阶段丢过零、静止准入和故障不重启。这是预设转子轨迹的电气采样模型，尚未辨识实际惯量／摩擦，也不能代替上板验证。

为了继续容纳全部功能，仅 UI 应用文件改为 `-Oz`，控制、HSO 和其他外设仍沿用上一版编译设置。有限输入下的静止判据／电压残差计算做等价整理，未删减原有功能或保护。Debug/Release、原控制／HSO／UI／存储回归和链接后固件一致性检查通过，尚未烧录 R62。

## R61 启动修正

实板反馈：4015、12 V、空载、Speed 30 rad/s，起转持续震动，最终 START TIME，Qual 0/12，事后 Duty 0%、EMF 1.99 V。START TIME 表示 8 s 内未满足过零闭环接管；R60 停机清零 Duty，因此该零值不能证明启动时没有驱动。单个 EMF 值也不能证明有有效过零，尚不能仅凭这些值确定实板根因。

本轮针对六步输出和开环启动修正：

- PWM 高相的互补低侧在 OFF 期间导通，使用现有 TIM1 死区，提供确定的续流和自举电容充电路径；浮相仍为上下管都关闭。原版高相低侧始终关闭，只能依靠二极管续流／绕组路径。
- 起步电频率由 3 Hz 降为 1.5 Hz；低于 6 Hz 时按 3 Hz/s、高于 6 Hz 按 10 Hz/s 加速。TIM7 长步支持 4 μs 分辨率，解决原 65 ms 上限无法生成慢速起步的问题。
- 对齐电压用两相串联的 2×Rs 和 50% rated_current 计算；开环阶段的保持电流基值降至 25%，另加原速度前馈，减少空载强磁场逐步拖动。启动相电流上限仍为 60%，保护未放宽。幅值约束使用约 1 ms 滤波，原逐帧峰值／IBUS 保护继续使用原路径。
- 速度环接管时按当前占空比预置积分，避免接管电压跳变。仍要求约 12 Hz 与连续 12 次有效过零，未通过降低资格要求掩盖失步。
- 六步自身故障保留最近 Duty 和 EMF；此时输出已关闭，Duty 表示故障前命令，不能读作仍在输出。普通 Stop 清零 Duty。

主机两相 RL 电路、正反转合成过零、真实采样后台、原有 UI/控制/HSO/保护回归通过。它们不能证明本次实板震动已消失；需要重新烧录 R61，在同样的 4015／12 V／空载／30 rad/s 条件复测。若仍失败，记录 ALIGN 是否能稳定保持、RAMP 是否连续转动，以及失败后的 Qual、保留 Duty、EMF，再决定是否调启动电压或检查相端波形。

## 选择与启动

1. 停机并等转子停止，选择 Settings → System → Work Mode → Single M1。
2. 按原方式为 M1 选择 2804 或 4015；其 Rs、额定电流、额定速度及电压用于六步的启动和速度控制初值。
3. Settings → System → Six Step → ON，确认保存。它与 HSO Feedback 互斥；打开 HSO 会退出六步。运动中拒绝更换驱动方式。
4. Run 显示 `M1 Throttle 6STEP` 或 `M1 Speed 6STEP`，左右短按切换，保持原上下加减／长按连发／OK 确认规则。先以 4015 空载、Speed 30 rad/s 复测接管，再试油门 20%；真实启动电流和过零质量仍需上板调试。

串口可依次使用 `Work:SingleM1`、`Feedback:SixStep`、`Speed:30`。前两条是主循环配置任务，等待配置执行后再发送速度。`Feedback:Encoder`／`Feedback:HSO` 选择原有驱动，`Stop`、`Speed:0` 和 KEY1 均能停止六步。

停止采用滑行；反转须先停止，电气静止连续确认 200 ms 后再发送新方向。释放 KEY1 不自动重启。六步自带启动对齐，不执行编码器对齐；System 的 Align / Retry 不用于此模式。切回编码器后，若未完成编码器对齐，仍需原有对齐操作。

六步菜单仅在 Single M1 可用。切到双机／Single M2 时取消六步运行并恢复 TIM1 原 PWM1 模式，双电机继续全有感。六步偏好保留，回到 Single M1 也不会自动启动。

六步 Speed 命令电频率范围为 12～200 Hz，还受当前轴 Speed Limit 限制；这不是 Throttle 的百分比范围，也不是接管必须达到的转速：

| 电机 | Run 可选非零机械速度，rad/s |
| --- | --- |
| 2804，7 极对 | ±10.8～±179.5 |
| 4015，11 极对 | ±6.9～±114.2 |

零值滑行停止；编辑跨过低速禁区时直接到零，运行中禁止直接反转。原 FOC/HSO 速度范围不因此缩小。六步下 Curr Loop 显示 OFF 且不可编辑，保留原编码器电流环偏好，返回 FOC 后仍按原设置应用。

Run 显示 `6STEP ALIGN`、`6STEP RAMP`、`6STEP SYNC`、`6STEP RUN` 或失败原因。Status → Drive 末尾显示物理 M1 的 `6S ZC`（连续有效过零、门槛代码及最近候选百分比）、`6Step Duty`、`6Step EMF`、`6Step Speed`。六步不输出绝对机械角／精确电角度或 dq 电流，相关 Motion 数值显示 `--`；Encoder 诊断页仍可检查实际编码器。

遥测保留 25 路帧结构：六步启用时，0 为目标（根据通道 23 区分：0=油门百分比，1=Speed rad/s）；1/7 为估计／参考机械速度（启动时为强制参考，油门 RUN 时参考随估计值）。16～21 为实际命令占空比、过零残差 V、扇区 0～5、连续有效数、累计过零数、状态（R62 起 IDLE=0、ALIGN=1、RAMP=2、SYNC=3、RUN=4、FAULT=5）。其他驱动方式沿用原映射。

## 启动、采样与保护

六步顺序为 U+V−、U+W−、V+W−、V+U−、W+U−、W+V−；反转反向推进。使用 FD6288Q 的独立 HIN/LIN：高相使用带原死区的互补 PWM，低相强制低侧导通，浮相主输出强制无效、互补输出关闭。TIM1 OSSR=1 保持浮相两输入无效。先断开相输出再改模式；不启用会延迟既有 CCER 停机的 CCPC 预装载。所有 CCR 共用占空比，因此换相时不继承另一相的旧占空比。

先以 1% 占空比开始，400 ms 内升到对齐电压，固定扇区对齐 1 s。随后推进两个扇区起转，电频率从 1.5 Hz 按前述两段斜坡开环升到最高 20 Hz（Speed 目标较低时跟随目标上限），按 R63 的资格分别进入换相同步和运行控制。启动总超时 8 s。启动／SYNC 相电流限幅目标为预设 rated_current 的 60%，RUN 时为 rated_current；这是基于 ON 时刻电流的幅值约束，不能当作经过标定的连续热保护。硬件 IBUS、相电流峰值和原过载预算仍独立生效。

保留 10 kHz 中心对齐和现有双 ADC 注入顺序。R67 六步按实际 duty 在 CH4 峰顶 OFF／谷底 ON 中选择，其他控制仍为谷底；仅在完整采样窗、输出确实有效、中心至采样期间未换相时接收过零数据。换相后屏蔽至少 200 μs 或该步时长的 15%。将早采的 V 相按现有 40 μs RC 模型投影到 U/W 的 Rank3 时刻，使用三相共模抵消后的浮相残差；不直接比较滤波后的浮相与未滤波 VBUS/2。过零插值、约 40 μs 低频滤波延迟补偿以及两帧滞回确认后，按约 30° 电角度延迟换相。实际 RC、钳位、退磁和电流波形仍需实测核对。

固件使用此前空闲的 TIM7 做单次换相定时和丢过零看门狗，由应用初始化：延时不超过 65 ms 时为 1 μs 分辨率，慢速起步长延时为 4 μs，最长 260 ms。**本轮不需要在 CubeMX 增加配置**，也不要再把 TIM7 分配给其他功能。ADC/PWM 频率、APB 时钟和其他通信速率保持原值。

丢过零时 TIM7 到期停机，不无限按旧速度盲换相；采样故障、KEY1、IBUS Break 撤销输出并取消定时器。保护清除不请求输出；下一次手动启动仍须满足静止和采样准入。常见失败：`6STEP START TIME`（开环期间未接管）、`6STEP NO ZC`（运行丢过零）、`6STEP PHASE`（过零周期／相位失配）、`6STEP LATE ZC`（换相目标已过期）。

六步偏好使用 v3 control_config 空闲 bit14；v1/v2/旧 v3 默认关闭，记录长度和 CRC 不变，IBUS 位域和独立轴焦点不受影响。
