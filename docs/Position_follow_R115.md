# 第 6 批：位置与 Follow，R115

固件 `UI-R115-POS`，Native 回执版本 115，单 HTML 兼容范围同步更新。基线为 R114。此次优化普通编码器速度／位置控制的饱和处理、同步位置的参考跟踪，以及已有 4015 电流模式快速 Follow；不新增存储字段或设置项。

## 修改

### 编码器速度 PI 的条件积分

R114 只在快速 Follow 中冻结继续推向饱和的积分，普通位置／速度模式仍可能累计到积分上限。本版将相同处理用于两轴全部编码器速度 PI：输出已达限幅且误差继续推动同方向时，撤销本周期积分增量；反向误差仍能解除饱和。M1 Speed 与 Position 共用同一速度控制入口，M2 同样执行。

保持原限流、限压、积分／输出上下限。冻结不会清除已有负载积分；使用梯形积分时，误差突变后仍可能有一个采样周期的小增量，不宣称任意切换都会严格零输出。HSO 的速度 PI 明确绕过此次新条件积分，保持已验证的 R113 算式；六步保持独立控制。

### 同步位置的速度前馈与制动

原同步位置协调器已经产生参考位置及速度，但位置控制器只用位置误差生成速度指令，必须出现落后才能追赶。本版使用同一条轨迹的速度前馈：

```text
M1 速度目标 = 轨迹速度 + 位置修正
M2 速度目标 = 齿轮比 × 轨迹速度 + 位置修正
```

两轴最终目标仍通过各自限幅和速度参考斜坡。共享轨迹同时服从命令速度上限、两轴 Speed Limit 和按齿轮比换算的两轴 Pos Speed，修复“从轴 Pos Speed 很小，参考轨迹仍按较高速移动”的不一致。负齿轮比、偏置、反向和运行中降低上限继续支持。

前馈减少原有落后后，制动也必须预留内环响应时间。原 `sqrt(2*a*距离)` 改为带 30 ms 规划余量的停止距离包络，并与 Follow 共用包络计算函数：

```text
速度包络 = sign(距离) × [sqrt((a*T)^2 + 2*a*abs(距离)) - a*T]
```

30 ms 是待实板校核的保守规划初值，不是已经辨识出的电机时间常数。原加／减速度限值、目标位置和机械多圈关系保留。Stop 结束共享轨迹后不残留前馈。

### 快速 Follow

普通位置 P 保留 6；Follow 原位置修正 P 保留，未增加位置 I 或原始位置差分 D，未恢复曾导致实板振动的 R36 末端 PD。

1. 原快速 Follow 速度 P 仍在原 0.05～0.10 A/(rad/s) 范围内，但用 `g += 0.2*(g_target-g)` 平滑其调度，避免每毫秒直接随误差改变增益。低频时间尺度约 4 ms，每次 Follow 根据当前从机参数初始化，Stop／换主从后不继承旧会话状态。不是在编码器速度反馈上再加一层低通。
2. 使用已有约 10 Hz 的有符号主机加速度估计，加入有界参考速度前瞻：`clamp(4 ms × 齿轮比 × a_master, ±0.5 rad/s)`，再乘原快速活动度和小跟随误差权重。快速往复时才逐渐参与；已确认主机安静时关闭，大角差追赶权重降低时也退出。
3. 前瞻最终仍经过原 Pos Speed／Speed Limit 和加减速处理，不改变最终机械角目标，不把未经辨识的惯量换算成 Iq，也不新增摩擦电流猜值。
4. R37 之后的近静止保持、计数锚点、30/60 ms 安静确认、4/8 计数滞回、保留负载积分的处理继续存在。FOLLOW ERROR、编码器、ADC、过流、过载、Break、KEY1 和控制超时保护不放宽，恢复后不自动运行。

快速前瞻用于现有 `fast_tracking` 预设，即 4015／以 4015 为基础的自定义电机、Curr Loop=On，支持两轴交换主从。2804 和电压模式 Follow 保留原保守轨迹；通用条件积分及同步位置修正适用于两种型号和电压／电流模式。此次没有宣称已辨识所有电机／负载的带宽。

已核对 [SguanFOC 的三环控制流程](https://github.com/Sguan-ZhouQing/SguanFOC_Library/blob/main/SguanFOC库v3.1.0(无感foc，浮点运算，进阶)/SguanFOC.c#L1505-L1567)及 [PID 积分限幅实现](https://github.com/Sguan-ZhouQing/SguanFOC_Library/blob/main/SguanFOC库v3.1.0(无感foc，浮点运算，进阶)/Sguan_PID.c)。参考其串级、限幅思想；此处同步轨迹前馈和 Follow 前瞻是本工程实现，不把它的本机速度补偿等同于主从前馈，也未整体移植该库。

## 验证与效果范围

所有下列运动结果均是独立执行器模型，不是板上测量。模型包括真实 1 kHz 外环／协调器、两轴 FOC 路径、14 位量化和估计器；电流执行器为 250 rad/s 一阶响应，电流到加速度增益为 300/1500/3000 rad/s²/A。Follow 模型另含静／动摩擦及小齿槽扰动，参数未实物辨识，也没有完整逆变器电压饱和、温度或机械共振模型。

| M1 从机、±10°／4 Hz | R114 | R115 |
| --- | ---: | ---: |
| 增益 300：位置幅值比 | 0.8744 | 0.9155 |
| 增益 300：周期相位差 | −39.37° | −35.60° |
| 增益 1500：位置幅值比 | 0.8895 | 0.9344 |
| 增益 1500：周期相位差 | −8.07° | −4.03° |
| 增益 1500：机械角误差 RMS | 1.2510° | 0.7236° |
| 增益 3000：位置幅值比 | 0.8683 | 0.9121 |
| 增益 3000：周期相位差 | −2.53° | +0.80° |

负相位为滞后，正相位为超前；周期相位不是电机机械角误差。M2 从机通过相同界限。原 4 Hz 界限全部保留，并收紧中／高执行器增益下的幅值、相位和误差要求。

中等增益、0.6±0.15 rad/s 的慢转／6 Hz 输入起伏模型中，目标 Iq 变化率 RMS 从约 0.819 降到 0.744 A/s，速度波动 RMS 基本不变（0.1797→0.1796 rad/s），不能据此称实际慢转速度起伏已经消除。滑行停止延迟约 27→26 ms；大角差拨转后的追赶到 0.1 rad 时间基本不变，某些微小尾部运动仍存在。停止保持／负载／重新运动及噪声界限未放宽。

同步位置的独立双轴电流模型使用反向 1:1、2 rad 目标和 3 rad/s 轨迹上限，统计移动阶段相对参考轨迹的误差：

| 执行器增益 | R114 参考误差 RMS | R115 参考误差 RMS | R115 最远位置绝对值 |
| --- | ---: | ---: | ---: |
| 300 | 0.42588 rad | 0.03404 rad | 2.0748 rad |
| 1500 | 0.42142 rad | 0.00423 rad | 2.0001 rad |
| 3000 | 0.42085 rad | 0.00413 rad | 2.0002 rad |

弱执行器模型仍有约 3.7% 超调，原模型则靠明显落后避免超调，不能将减小轨迹误差等同于所有工况都无超调。实板负载改变时需核对制动余量。

新增 0.5/1/2/3/5 Hz 扫频、非零相位突停后，电流模式覆盖 198 个工况，原 162 个界限不放宽。0.5～1 Hz 往复在原有静摩擦模型中就存在明显幅值损失，R115 仍未解决；不通过降低摩擦模型或放宽旧界限来宣称改善。后续若实板也复现，应先记录电流／角度并确定摩擦、内环响应，再决定补偿。

新增独立回归还覆盖：两轴不同电流／电压上限下的饱和释放和反向、正负 2:1 齿轮比／偏置、从机 Pos Speed 收紧共享轨迹、Stop 撤掉前馈，以及两次 Follow 的增益状态初始化。R114 在新增饱和释放回归中按预期失败，比较日志保留。

完整电机、R114 逆变器、HSO、六步、辨识、采样、编码器、协议、Native／JustFloat，UI／设置、HTML／Edge 握手、48 项 CubeMX 配置变更及两份实际 ARM 镜像启动／ELF-BIN 一致性检查均通过。
