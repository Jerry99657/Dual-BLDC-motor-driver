# 2804 / 4015 电机参数切换（UI-R24-MOTOR）

当前 **UI-R36-SMOOTH** 已接入双有感控制；本页早期版本说明保留作历史参考。当前逐路型号设置、HSO 入口及上板步骤以 [Dual_motor_control.md](Dual_motor_control.md) 为准。

本次选择作用于 **M1 驱动通道**。M2 仍只有采样与可选编码器诊断，不会因选择 4015 而使能第二路功率输出。

## 操作

1. 停止电机，进入 `Settings → Motor`。标题显示当前型号。
2. 上下选择 `2804` 或 `4015`，OK 打开确认框；默认焦点为 Cancel，右键切到 OK，再按 OK 确认。KEY2 取消或返回。
3. 确认不同型号时先撤下运行指令。编码器不健康、实测速度绝对值大于 1 rad/s 或正在对齐时拒绝切换，提示 `Stop/check encoder`；等电机停止/编码器恢复后再次确认。
4. 成功后切换全部控制/保护参数，清零三个模式目标及 PI/滤波状态，默认回到电压控制。编码器零点失效；采样和编码器就绪后，主循环执行原有 3 秒非阻塞对齐。对齐后仍需进入 Run 手动确认运行。
5. 等待 `Saved` 提示再断电。沿用停止、空闲约 2 秒后的异步 W25Q64 保存；若显示 `Save failed`，当前 RAM 中的选择已生效，但掉电恢复不保证。

Status 第一行 `Motor`、About 的 `Motor`、选择菜单标题均显示实际生效型号。首次使用旧设置记录时默认 2804，**当前连接 4015 的板子烧录后需要选择一次 4015 并等 Saved**。Reset 恢复默认时也回到 2804，若尚未停转/编码器异常则拒绝恢复，避免存储值与实际参数不一致。

实际更换电机前断开电机母线。可以保留 MCU/编码器供电、选择型号并保存；母线未就绪时不会执行对齐。连接正确电机及编码器后再恢复母线。参数选择不能替代接线相序与编码器方向匹配；仍沿用已经验证的接线方向。

电压上限不会改变电源电压。实际 PWM 电压矢量还受 `min(实测 VBUS, 配置电压) × 0.95/√3` 限制，因此 4015 档也可在 12 V 母线上低速调试，但不能保证达到 24 V 时的转速/转矩。共用的 ADC 参考、分流电阻、INA240 增益、ADC 越界及母线采样故障判据仍由硬件决定，不随电机型号修改。

4015 的 1.8 Ω 按用户参数图中的三角形绕组、线间电阻 3.6 Ω 折算。图中 1.3 mH 未说明测量方式，目前原值作为待核实模型值，不能据此认定电流 PI/HSO 已调好。电流 PI 初值按 Ls×250、Rs×250 配置。R29 将电压/电流模式的速度 PI 分开，R31 将两个型号位置 P 提到 6，仍是待上板整定的初值；详见 [位置响应调整](Position_response_tuning.md)。

4015 的 1.2/1.4/2.5 A 是调试预设，使用 dq/相电流峰值口径，不是直接照搬铭牌额定 1.4 A 或堵转 4.9 A，也未经过板上温升与带载验证。电压控制模式不主动恒流；1.2 A 只限制启用 Curr Loop 后的 dq 指令，并用于对齐电压计算。

## 过载与故障

继续按原始三相电流计算：

```text
Ivector² = (2/3) × (IU² + IV² + IW²)
budget += Ivector² - overload_current²
budget = max(budget, 0)
budget >= overload_current² × 10000 × overload_budget_s 时锁存 M1 OVERLOAD
```

4015 档从零预算开始，稳定矢量电流 1.5 A 约 20.3 秒、1.8 A 约 4.6 秒、2.0 A 约 2.9 秒触发。低于基准时预算逐渐下降。这是超额平方电流累计保护，不是已标定的绕组热模型，`3 s` 不是固定跳闸延时。

切换不清除 ADC/过流/过载等采样故障，也不重启 ADC 来清除过载预算。故障已锁存时可以在健康编码器/停转条件下选择并保存新型号，但故障仍需排除原因后复位；不能借切换型号自动恢复输出。两种型号使用不同基准，未触发的已有预算会继续保留并按新基准累计/下降。

## 实现与兼容

- `JerryFOC_selectMotor()` 在主循环中以短临界区完成停输出、参数发布、PI/滤波清零、编码器重建与 HSO 初始化。硬件采样 ISR 从同一活动参数表读保护门限。
- 主循环通过 `JerryFOC_needsAlignment()` 接收重新对齐请求，Run 在编码器未对齐时拒绝启动。转速、位置速度、电压/电流指令在控制接口也受当前型号约束，串口不能绕开型号硬上限。
- HSO 切换时清除旧磁链学习、资格、失锁历史与观测快照，不自动接管；需给新电机重新辨识/设置磁链。原有 HSO 45 rpm 返回策略保持。
- 型号保存在 version 2 记录 flags 的 bit24。保留记录大小、A/B、序号、CRC，以及旧 version 1 迁移；旧记录 bit24=0 对应 2804。Run 的目标在切换时清零；LED、Run Steps 保留，Speed Limit / Pos Speed 采用新型号默认值。
