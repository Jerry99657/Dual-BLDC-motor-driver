# 标准 Demo

首次移植需要初始应用且用户没有明确产品界面需求时，默认安装完整标准 Demo。已有产品界面和本地修改保留，具体产品需求优先。Demo 源码、字模、图标与资源记录来自正式参考应用，不从零拼装最小菜单。

## 安装与调用

从 [Demo 资产](../assets/kk-ui-demo/) 复制可编辑副本到项目源码目录，或运行 `scripts/install_demo.py <新目标目录>`。已存在目录或符号链接目标拒绝写入，不直接从 Skill 资产参与构建。应用需要 KK_UI 全功能和 KK_OLED 的 `OLED_SetContrast()`；旧版运行时缺少 `KK_UI_GetIntEditorDraft()`、`KK_UI_IsDisplayIdle()` 时，先比较并增量更新项目副本。

```c
/* 平台、OLED 初始化成功后。 */
KK_UI_AppReset(now_ms);
KK_UI_Init(KK_UI_AppGet());

/* 主循环或同一线程；不可颠倒顺序。 */
KK_UI_AppUpdate(now_ms);
status = KK_UI_Update(now_ms, input);
KK_UI_AppProcessEvents();
```

GPIO、总线、KK_OLED driver、时基和构建由目标工程提供。应用只提交 OLED 对比度控制命令，不并行清屏或提交完整画面刷新。KK_UI 更新建议至少每 10 ms 调用一次。

## 页面与操作

上电停在图标首页的“设置”，四个入口依次是设置、数据监测、波形、关于设备。首页上下选择、确定进入。非根菜单自动追加返回；从子菜单返回恢复父页面焦点和滚动位置。

| 设置条目 | 演示内容 |
|---|---|
| 屏幕亮度 | 10～100%，默认 80%，步长 1%；编辑时实时预览 OLED 对比度，确认保留，取消回滚 |
| 开关 | 默认开；只演示开关编辑与状态显示，不接蜂鸣器 |
| 组件演示 | 进入动画间隔、条目显示和禁用的子菜单 |
| 确认框 | 显示“恢复默认设置？/包含屏幕亮度”，默认选中取消；确认恢复五项参数 |
| 消息框 | 标题显示“这是消息框”，正文显示“确定关闭”，确定退出 |
| Toast | 显示“这是 Toast 提示”，自动消失 |

组件演示子菜单包含动画间隔、显示条目、禁用条目、操作示例。动画间隔默认 20 ms，范围 10～100 ms，步长 10 ms，实际调整波形移动速度，不修改 KK_UI 帧调度。显示条目关闭会隐藏操作示例；禁用条目开启会使它可见但不可操作。隐藏优先于禁用；两个控制项及返回始终可达。操作示例触发“操作已触发” Toast。

整数和开关打开后先编辑数值，确定键进入按钮区，再确定键提交；选择取消则保留原值。恢复默认同时恢复亮度 80%、动画间隔 20 ms、开关开、显示条目开、禁用条目关；不清零运行时间，也不写入非易失存储。

数据监测依次显示运行时间、已确认的亮度参数、开关状态、动画间隔和亮度控制状态（等待、正常、不支持、失败）。关于设备显示 UI 版本、KK_OLED 逻辑尺寸、构建选择的 Blocking/IT/DMA 刷新方式、断电保留说明和操作提示。信息页上下滚动、确定退出。

波形页自动运行：每 50 ms 进度加 1，到 100 后回到 0；第一次方向键或编码器输入切换手动，下键增加、上键减少，限于 0～100。波形运动不停；确定退出、再次进入恢复自动模式。标题显示 `FPS:数值`，首次统计窗口完成前显示 `FPS:--`。FPS 是每至少 1 秒按实际 elapsed 时间统计的波形页绘制次数，包含切入转场，重复绘制回调同轮只计一次；不是 OLED 传输完成帧率。

## 亮度控制与适配

百分比按 `(percent * 255 + 50) / 100` 映射到 0～255 对比度。应用在 UI 更新和传输结算后、显示空闲时发送命令；连续编辑只保留最新目标。BUSY 稍后重试，ERROR 显示失败且同一值不循环重试，新的操作可再次尝试。UNSUPPORTED 禁用亮度条目并显示不支持；本次运行不重复探测。实时预览无成功 Toast，确认或恢复成功后才提示更新。对应的真实屏幕亮度效果取决于移植的 OLED 控制器和 driver；移植时检查 `OLED_SetContrast()`，不要把仅变化的菜单数值当作硬件功能完成。

## 视觉、字模与验收

128×64 基准为 32×32 图标、首页/标题/正文字号 14/12/14、菜单行高 16 px、三行完整可见、首页/菜单动画 300/200 ms。更换 MCU 或总线时保持；其他逻辑尺寸由 `kk-ui-port` 适配并报告差异。文字与字号不变时复用配套字模；新增字符、缺字或字号变化时按 `kk-oled-font` 生成完整子集。来源与许可情况见资产内的资源记录。

验收启动首页、四个入口、菜单滚动与返回、编辑确认取消、实屏亮度预览与回滚、BUSY/失败/不支持状态、组件隐藏禁用及焦点修复、确认框、消息框、Toast、波形自动/手动进度、FPS 数值和页面边界。真实 framebuffer 预览检查字形、排版与中间帧；GIF 不模拟实际亮度变化。区分软件模拟、目标构建和板上实测证据；没有烧录时将板上操作和亮度效果列为待验证。
