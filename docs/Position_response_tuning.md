# UI-R29-POSLIM：位置响应与手动跟随

当前 **UI-R36-SMOOTH** 为 4015 电流手动跟随加入快慢通道、输入整形和末端位置捕获，见 [4015_smooth_follow.md](4015_smooth_follow.md)。普通 Position / Sync Position 仍用 R31 的 P=6。以下保留 R29～R31 的调参记录，不再代表当前手动主从的控制公式。

R31 将 2804/4015 的位置 P 从 4 提到 6，位置 I=D=0，速度 PI、速度前馈与加减速限幅继续沿用 R29。当时 M1/M2 的普通 Position、同步位置和手动跟随均使用各自型号的这个位置增益。无需修改 CubeMX。

用户描述的“大角度落后后，接近主轴时速度逐渐变慢”符合当前控制公式：`目标速度 = 主轴速度前馈 + 位置 P × 角度误差`，再按 Pos Speed / Speed Limit 限幅。主轴停下后，前馈降为 0，剩余误差越小，追赶速度越小。以 5° 误差为例，P=4 时修正速度约 0.35 rad/s，P=6 时约 0.52 rad/s；这是修正目标，不是实测速度。

当前症状优先提高 P。位置 I 适用于确实存在持续静差的情况；大角度和输出限幅下积累的积分可能使轴越过目标，需要积分限幅/分离和抗饱和处理，不能直接靠加 I 消除减速。位置 D 用于抑制超调/摆动，通常不用于让追赶更快；若之后需要 D，应结合速度内环整定，并优先用滤波后的相对实测速度实现阻尼，避免目标跳变引起微分冲击。参考 [串级位置环调参](https://docs.simplefoc.com/angle_cascade_control)与 [积分饱和及抗饱和](https://www.mathworks.com/help/simulink/slref/anti-windup-control-using-a-pid-controller.html)。本轮继续采用位置 P + 速度 PI，未加入位置积分或微分。

本轮针对用户报告的 4015、Pos Speed=30、Speed Limit=120、Curr Loop=Off，以及两个型号位置模式响应偏慢进行调整。无需修改 CubeMX；主轴在手动主从模式仍关闭功率输出。

## 检查结果与控制结构

实际控制是位置 P → 速度 PI → Uq 或电流 PI，不是位置 PID 直接输出力矩。两个型号旧位置 P 都为 2，I=D=0：90° 误差最初只产生约 3.14 rad/s 的目标速度，接近目标时继续减速。把 Pos Speed 调大也不会让这个小误差指令自动达到上限。

4015 的速度 PI 原先与 2804 共用 0.05/0.5 的数值，电压模式与电流模式也共用同一组增益。用户当前电压模式没有主动电流调节，速度内环响应会直接影响位置响应；仅加大位置 P 可能增加来回摆动，不能认定加 D 就会解决。

保留位置 P + 速度 PI 的串级结构。位置直接控制力矩时常用 PD；当前结构已有速度反馈，额外对位置误差做差分会引入目标突变冲击和编码器噪声。调参应从内环到外环。可参考 [SimpleFOC 串级位置控制](https://docs.simplefoc.com/angle_cascade_control)、[非串级位置控制](https://docs.simplefoc.com/angle_nocascade_control)和 [MathWorks 串级控制调参示例](https://www.mathworks.com/help/control/ug/designing-cascade-control-system-with-pi-controllers.html)。这些资料支持结构选择，不代表本板增益已被实测验证。

## 本轮增益

| 参数 | 2804 | 4015 |
| --- | --- | --- |
| 位置 P | 2 → 4（R29）→ 6（R31） | 2 → 4（R29）→ 6（R31） |
| 位置 I / D | 0 / 0 | 0 / 0 |
| 电压模式速度 P / I | 0.05 / 0.5，保留 | 0.05 / 0.5 → 0.1 / 1.0 |
| 电流模式速度 P / I | 0.05 / 0.5，保留 | 0.05 / 0.5，保留 |

参数在 `motor_params.c`。`vel_P/I` 输出单位对应 V，`vel_current_P/I` 对应 A；M1/M2 在切换 Curr Loop 时分别加载相应增益并清理旧积分状态。型号切换仍重新加载对应控制器，不混用另一轴的状态。电流 PI、采样滤波、100/150 rad/s² 加减速限制、电压/电流/过流/过载门限保持原值。

这是待上板确认的响应初值，不能保证任意惯量/负载下都无超调。若出现振荡，需要结合目标速度、实际速度、实际角度和输出限幅整定速度环，再调整位置 P。

## Pos Speed 与 Speed Limit

`Settings → Pos Speed` 可设 **1～当前查看电机的 Speed Limit**。例如 4015 的 Speed Limit=120 时，Pos Speed 可设到 120；2804 的 Speed Limit=600 时可设到 600。降低 Speed Limit 会收回超出的 Pos Speed，切换 M1/M2、切换型号和重新加载均更新编辑器范围。

原来保存的 30 会保留，不自动改成最大值。此次 4015 可先把从轴 Pos Speed 提高到 60，再根据带载响应逐步增加。Speed Limit 是总上限，Pos Speed 是位置模式的独立上限；两者均为 rad/s。

原 Pos Speed 仅在 flags[13:8] 保存 6 位，最多 63；现在保留这 6 位，并用原空闲 flags[28:25] 保存高 4 位。必须通过 `AppSettings_GetPositionSpeed` / `AppSettings_EncodePositionSpeed` 读写，不能直接整体移位，否则会覆盖 Speed Limit。记录大小、版本 3、CRC、A/B 保存方式不变，旧 v1/v2/v3 数值继续兼容。M1 和 M2 使用各自的 flags。

手动跟随每个外环周期读取从轴的有效位置速度，最终不超过该轴 Speed Limit / 型号上限；普通 M1/M2 Position 命令也受 Speed Limit 限制。提高的是允许范围，现有加速斜坡和实际电机能力仍会限制响应。

## 手动跟随与误差停机

旧代码把手动跟随与同步轨迹共用“误差超过 1 rad 持续 500 ms”规则。手转时主轴可以突然加速，从轴受速度和加速限制，暂时落后并不代表编码器或闭环故障。

同步速度/位置模式继续使用原 SYNC ERROR 规则。手动主从改为 FOLLOW ERROR，在启用 3 秒后检查：

- 偏差绝对值超过一机械圈（2π rad），持续 500 ms，停止跟随，避免累计过长的追赶位移。
- 偏差超过 1 rad，主轴基本停止（速度绝对值小于 0.5 rad/s），从轴没有向目标追赶（朝目标方向的实测速度未超过 0.1 rad/s），持续 500 ms，停止跟随。
- 手转期间的短暂落后、从轴正在朝目标追赶时，不因旧的 1 rad 门限单独停机；超过一圈的限制仍有效。

这不是取消保护。编码器失联、ADC/母线/参考异常、从轴电流故障、控制超时继续按原规则停止；恢复不会自动重启，重新按 OK / Follow 才抓取新的两轴起点。

## 验证

真实控制代码主机测试覆盖两轴高于 63 的位置速度、运行中降低速度上限、电压/电流增益切换、暂时落后后的追赶、主轴停下而从轴不动、偏差超过一圈停机。UI 与真实 NOR 模型覆盖两种型号/两轴的 600/120 上限、降低后的钳制、保存重载、旧记录兼容和其他 flags 不被覆盖。

另外用真实 1 kHz 控制器驱动一阶理想电压—速度模型，比较 P=4 与 P=6 的 1 rad 阶跃，速度 PI 保持各型号 R29 预设，时间常数取 5/20/100 ms。到达目标 90% 的时间：2804 约 0.49～0.55 s → 0.34～0.40 s；4015 约 0.51～0.56 s → 0.39～0.42 s。

模型同时记录最终收敛及峰值，并没有只检查变快：P=6 时模型超调更大，部分工况进入并保持 ±0.02 rad 的时间也更长（如 4015、100 ms 模型约 1.25 s → 1.40 s）。因此“更快接近”不等于“所有工况都更快稳定”。模型没有实测惯量、负载、电流和热行为，只用于回归比较，**不是板上性能或稳定性验收**。需要上板观察是否出现越过目标或来回摆动，再决定速度内环和阻尼的下一步整定。
