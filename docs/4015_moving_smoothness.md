# UI-R38-SMOOTH：改善手转过程的快慢起伏

本页记录 R38 控制算法。当前 R39 保留此算法，仅将编码器通信时钟减半，烧录版本与时钟说明见 [Encoder_SPI_slow_clock.md](Encoder_SPI_slow_clock.md)。下文 R38 固件标识及资源数据保留作历史记录。

用户已确认 R37 的结束高频振动改善，但手转过程中仍有快慢起伏，且不固定在相同机械角度。本轮保留 R37 的停止保持，调整主机输入整形；不直接套用按角度补偿的齿槽表。适用于 4015 从轴、Curr Loop=On，两轴可交换主从，无需修改 CubeMX。

## 修改依据

R37 的慢速位置低通截止频率由另一条速度估计逐帧调节，前馈速度又由位置滤波增量产生。在未进入静止处理时：

```text
v_ff[k] = alpha[k] * (p_master[k] - p_filtered[k-1]) / Ts
```

因此截止频率改变会调制前馈速度，不能只把输出起伏归因于原始手速。另一个限制是原运动活动度在速度约 0.7 rad/s 时就进入完整快速通道，普通手转也容易绕过慢速整形。以上是代码与模型分析，尚未通过实机曲线认定全部原因。

[Synapticon 的速度前馈说明](https://doc-legacy.synapticon.com/software/42/motion_control/advanced_control_options/feedforward/index.html)说明，对目标位置求导会受到量化、输入噪声和通信抖动影响，需要滤波，并注意滤波和动态响应的取舍。本轮沿用这个输入侧处理方向；下面的归一化参数是本项目模型验证后的实验值，不是厂家的通用推荐值。

## 当前实现

1. 保留 R35/R37 两轴 alpha-beta 速度观察器和从机反馈带宽。只从主机相邻观察速度之差计算加速度，并先经过约 10 Hz 有符号低通，再取绝对值。
2. 运动活动度输入改为 `clamp(max(abs(v_master)/4, abs(a_filtered)/25),0,1)`，再按原约 50 ms 时间尺度平滑。4 rad/s、25 rad/s² 是识别运动活动度的归一化基准，**不是电机的速度或加速度限幅**。
3. 活动度在 0.3～0.7 之间连续形成快速通道权重 `b`。同一个权重同时控制输入低通截止频率 `fc=5+95*b` Hz 和快慢通道融合，取消独立原始速度差分调制截止频率的路径。
4. 平缓手转主要采用 5 Hz 输入整形。快速往复的加速度会保持快速通道，避免单凭瞬时速度小就把换向误判为慢转。
5. 主轴安静时，快速权重为零，位置滤波提高到 100 Hz 以消除尾部，前馈速度继续按 R37 的方式衰减。R37 的运动锚点、30/60 ms 确认、4/8 计数保持滞回和负载积分保留。

参考位置与速度仍连续进入原受约束追赶轨迹，最终目标仍是真实主轴机械角度。普通 Speed/Position、其他型号和电压模式仍使用原控制预设；没有增加速度环 P、末端 D、未经辨识的摩擦电流或全局电流限斜率。

## 模型验证

调用真实双轴协调器、外环、FOC 和协议，保留原 14 位量化、250 rad/s 一阶电流执行器、静/动摩擦及齿槽扰动模型，电流到加速度增益为 300/1500/3000 rad/s²/A。参数尚未实物辨识，不能替代实际 RL/PWM、电压饱和、惯量、温升与机械共振验证。

新增两轴各三种执行器下的 0.6±0.15 rad/s、1±0.2 rad/s 的 6 Hz 手速变化，0.6 rad/s 匀速，1 rad/s 加 80 Hz 单计数主机噪声、0.6 rad/s 加 37 Hz 单计数噪声，以及 0.6±0.15 rad/s 的 1 Hz 有意变速。总共 162 个电流模式工况；保留全部 R37 瞬态及保持界限，只收紧一项既有慢转波动界限并增加移动工况验收。

下表为 M1 从轴；M2 同样通过相应界限，统计去掉最初 1 s。

| 指标 | R37 | R38 |
| --- | --- | --- |
| 0.6±0.15 rad/s、6 Hz，输出 6 Hz 速度分量幅值 | 0.124～0.217 rad/s | 0.068～0.114 rad/s |
| 1±0.2 rad/s、6 Hz，输出 6 Hz 速度分量幅值 | 0.140～0.257 rad/s | 0.083～0.150 rad/s |
| 上述两工况，目标 Iq 变化率 RMS | 1.34～1.77 A/s | 0.82～0.88 A/s |
| 1 rad/s 加 80 Hz 主机噪声，目标 Iq 变化率 RMS | 2.16～2.23 A/s | 0.85～0.90 A/s |
| 1 Hz 有意变速，输出幅值相对 R37 | 基线 | 保留约 95%～96% |
| ±10°、4 Hz，位置幅值比 | 约 0.87～0.89 | 约 0.87～0.89 |

两项 6 Hz 速度分量分别减少约 46%～48% 和 41%～42%。这只代表指定频段，不是所有实际速度 RMS 都下降同样比例；模型中静摩擦、齿槽和内环响应引起的起伏仍然存在。1 Hz 弱执行器模型仍保留原有幅值放大，不能宣称所有有意运动都已经精确重合。

原位置阶跃、反向、偏置、负齿轮比、限速变化、4 Hz 往复与结束停止、噪声保持、负载保持、停后重新运动、编码器故障和重启检查通过。每帧仍检查输出未被意外停止、Iq 不超过 ±1.2 A；保护阈值保持原设置。

## 平顺与延迟的取舍

平滑会增加运动中的角度滞后。0.6 rad/s 工况位置误差 RMS 约从 0.011～0.014 rad 增至 0.023～0.024 rad；1 rad/s 工况约从 0.008～0.009 rad 增至 0.033～0.034 rad。停下后仍追赶原始目标，不把滤波后的角度当成最终目标。

滑行停止模型中，以从轴最后超过 0.02 rad/s 定义的速度停止延迟，R37 约 0～15 ms，本版约 21～33 ms，仍通过原 50 ms 界限。保持和负载恢复检查继续通过，但这不等于实机振动和停止时间已经验证。此次明确优先改善平缓手转时的输入波动，不能承诺既完全滤除手速变化又毫无跟随延迟。

## 上板与后续定位

烧录当前 Debug 或 Release，About → FW 应为 **UI-R38-SMOOTH**。继续使用从轴 4015、Curr Loop=On、Pos Speed=120、Speed Limit=120，先比较同样慢转、滑行停止，再逐步恢复 ±10°、4 Hz。无需重新生成 CubeMX 或修改设置保存格式。

若仍有起伏，记录主从速度、位置和从轴实际 Iq，比较主机本身的手速变化与从机额外产生的变化。JustFloat 的 M1/M2 位置为第 14/20 通道，速度为第 2/18 通道，M2 实际 Iq 为第 21 通道，原始跟随误差为第 25 通道。当前没有凭空填入惯量或摩擦补偿表；更高电流—加速度增益和真实负载仍需实测辨识。

## 构建

电机/采样/编码器/HSO/协议、UI/存储/LCD、USB CDC 主机回归通过；Debug、Release 构建与最终 ELF/BIN 启动顺序、一致性检查通过。新增计算在 1 kHz 命令协调路径执行，实际双轴中断耗时仍需上板确认。尚未烧录或进行本轮硬件闭环测试。

Debug：Flash **130980 / 131072 B**，余 **92 B**；RAM **21616 B**。Release：Flash **130212 B**，余 **860 B**；RAM **21520 B**。本轮没有进一步更改编译优化选项，Flash 仍接近上限。
