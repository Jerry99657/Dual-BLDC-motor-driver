# R78：M1 参数检测跨零缺样处理

用户随后已实板确认 R78 极对数／电阻测量正确。当前扩展版本为 [R79：Ls／磁链／Ke](Motor_detect_R79.md)，继续保留这里的限时冻结机制。

固件 **UI-R78-ID**。用户在 `POLES +／POLES -` 阶段、I test=300 mA 时退出为 ENC1 Lost；记录为 Frame=15、Err=15、Age 当前 0～1／历史最大 5、Last=ALL0、Zero=NEAR 3、Zpre=1、Zpost=16383、ZTime=0。

## 判断依据

`1 → 0 → 16383` 与反向跨越 14 位角度零点一致，最近一次全零事件之后已有有效角度。ZTime=0 表示起止落在同一个毫秒计时值内，不代表耗时为零。Frame 是累计帧级错误数，Last 保留上次错误，Age 的右值是历史最大值；不能用这些字段推断编码器当前仍在持续发送全零。Probe／Total 是 ENC2 的可选探测信息。

原驱动将全零帧作为模糊帧拒收：角度和状态均为零时 CRC 也可为零，但 MISO 断线／被拉低也可产生相同数据。因此仅凭一个全零帧不能确认传感器正常。拒收时保留上次有效角度，既不刷新有效样本计数，也不刷新时间戳；正常有感运行超过 **3 个控制周期**没有新角度便失联。用户记录的最大 Age=5 已越过该门限，R77 检测也会立刻退出。

## 修复范围

仅在 M1 检测的正反向扫角及其保持阶段增加有限的近零缺样判定。需同时满足：

- 已有有效、未进入 SPI 故障恢复的 ENC1 历史样本；
- 最近错误为 ALL0，当前零帧事件尚未被后续有效帧结束；
- 零帧事件开始时，上一有效样本仍在原 3 周期新鲜度窗口内；
- 上次有效原始角度距零点最多 2 个编码器计数；
- 距上次有效样本不超过 **50 个 ADC 周期／5 ms**，超出任一截止条件即拒绝。

该窗口内冻结检测的扫角、调节和测量进度，保持上次已限幅的 PWM 矢量；采样端的相电流、过载、母线及硬件 Break 保护继续执行，任一保护触发即撤销输出。下一有效帧到达后，按原解绕逻辑补入位移并继续调节和扫描。正反向终点结算继续要求原严格健康状态，缺样等待期间不能完成检测或发布结果。**不将全零帧发布为有效角度，不伪造有效计数，不清除诊断错误。** 正常有感 FOC 的 3 周期门限、ENC2 的五次停止／重试策略、SPI 速率及原保护保持。

电阻检测／启动仍使用严格准入；CRC、磁场、SPI 故障、远离零点的跳零、无有效历史、过期历史及持续全零均不能借此延长检测。超出窗口时关闭输出，保留 ENC1 Lost，并等待用户重新启动。

## 验证

使用相同的、拒收零码并保留上次角度的独立电机模型：保存的 R77 检测器会复现 ENCODER1 LOST；R78 对 2804／4015、编码器正反方向、跨零和扫角末端慢速驻留均能完成，电阻和极对数结果保持一致。模型仍运行真实检测器、FOC 调制器、ADC 调度及 1 kHz 外环。

实际编码器驱动测试逐周期核对：正常健康状态只允许 3 周期，近零缺样只允许到第 50 周期，第 51 周期拒绝；保留角度及有效样本计数不变；后续有效帧结束事件；CRC、远端跳零、无历史和毫秒超时拒绝。原电机／HSO／六步／编码器／SPI2 Flash／协议以及 UI／存储／LCD 回归通过。HAL、ST 库、KK_UI 核心及中断分发源文件未修改。

为容纳修复，检测电流上升段先在整数域限制计数后再换算，保持原 0.2 秒上升及幅值；无结果占位行复用 `NO DATA`。无需修改 CubeMX。
