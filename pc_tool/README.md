# 双电机控制台 R87（单文件 HTML）

`index.html` 是完整的离线上位机。界面、Web Serial 通信、协议解析、曲线、CSV 记录／回放和配置查询都内嵌在文件中，无需 Python、安装依赖或运行后台。

## 使用

1. 板子使用本项目 `UI-R87-PC` 固件；构建产物位于 `build/Debug/`、`build/Release/`。
2. 用桌面 Chrome／Edge 打开 `pc_tool/index.html`。也可以把这一个文件复制到其他位置打开。
3. 点击“选择串口并连接”，在浏览器对话框中选择 USB CDC 或 USB 转 USART 的串口。USART1 保持 **115200、8N1**。
4. 工具首先发送 `Get` 读取板端配置。连接不会自动运行电机，也不会用网页残留值覆盖板端设置。
5. 按工作模式、电机与驱动、Run 面板操作。切模式／型号／驱动沿用板端原有停机、轴使能、编码器及保护条件。

浏览器会要求串口授权；不支持 Web Serial 时页面会提示更换浏览器。`start.ps1` 仅为打开 HTML 的可选快捷方式。板子的 USB CDC 驱动或 USB 转串口驱动仍由操作系统提供。

“离线演示”保留模拟曲线预览，不打开串口或控制电机；`start.ps1 -Demo` 直接进入该模式。模拟记录使用 epoch -1，与实板连接分段区分。

## 本批已经提供

- 七种工作模式；两轴 2804／4015 型号；Single M1 的 Encoder／HSO／SixStep；六步的 ESC 通用选项。
- Speed、Angle、Torque、Throttle、Follow、单轴 Stop、全局 Stop、板端 View 选择，以及原始命令输入。
- 全部持久化数值设置的读回快照、保存阶段、当前工作模式／型号／驱动；现有状态和按需诊断通道。
- 请求编号、板端逐条受理／拒绝回执；超时显示“结果未知”，运动指令不会自动重发。实际限幅后的目标和运行状态以实时曲线／状态为准。
- 同单位曲线共用纵轴、无效值断线、采集组切换、暂停绘图、CSV 记录／回放、配置快照 JSON 导出。

HSO 只允许 Speed；ESC 通用六步只允许 Throttle，并显示电气 Hz。预设六步保留 Speed；双机均为有感。Torque 的单位依电流环设置为 A 或 V。保存的 Uq 不等于实时 Iq 目标。

工作模式、型号、反馈、Gear、Focus 通过现有板端配置入口修改真实 RAM 设置并请求保存。回执“已受理”与 W25Q64“已保存”是不同状态；保存可因 SPI2 占用而延后。读取全部设置可刷新最新保存阶段，板上操作后也应重新读取快照。

**按第 1～3 批交付边界**：Speed Limit、Pos Speed、步长、LED、IBUS 等其余 Settings 本批先查询，统一写入留待第 4 批；远程运动自动进入板端 Run 页及其草稿同步留待第 5 批。辨识远程启动和更完整诊断留待第 6 批。固化 PID／电机预设不新增编辑入口。

## 通信与记录

USB CDC 与 USART 共用数据帧；同一端口请由一个程序独占。本工具一次等待一条普通命令的回执；Stop 可打断等待。板端 Stop 立即执行并清空待执行队列；Key1 全局停止及原有保护持续有效。断开通信本身不等于停机。

使用支持本地文件写入的浏览器时，记录可直接写入选择的 CSV；其他情况下采用最多 16 MiB 的内存记录，到达上限自动导出并停止。暂停绘图仍继续解析与记录。回放展示最后一段采集组／重启分段的最近 20 秒，每通道最多 2200 点；回放期间阻止普通运动发送，全局 Stop 仍可用。

HSO 相对机械位置仍来自 HSO 电角度跨圈展开／极对数，不读取编码器；每次连续合格 CONTROL 重新建立零点，失锁／停机后无效。

`server.py`、`wire.py`、`requirements.txt` 保留作旧 Python 桥接和脚本／协议测试用途；本 HTML 不调用它们的 HTTP API，也不依赖 CDN。旧 R86 可接收原有遥测，完整控制与查询需 R87；配置握手未完成时禁止普通运动指令。

协议、Flash 实测与验证见 [R87 实施记录](../docs/PC_console_R87.md)。本次未连接真实串口、未烧录，已完成主机模型与构建验证；真实浏览器授权、长时间文件记录和 USB／USART 实板联调待验证。

接口依据：[Chrome Web Serial 官方说明](https://developer.chrome.com/docs/capabilities/serial)。
